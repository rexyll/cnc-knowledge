# CNC Knowledge

系统化整理数控机床及其直接相关产业链的工程知识库。

## 项目目标

建立覆盖数控机床产品、机械结构、零部件与材料、电气电子、数控系统、嵌入式软件、驱动与通信、控制算法、制造装配、性能测试、标准规范、维护维修、厂商供应链和智能化应用的可追溯知识体系。

## 目录导航

- `TaskPlan.md`：全库总计划、统一 Guide 与 Limit、任务治理规则。
- `docs/`：知识正文、章节索引与技术资料说明。
- `docs/TaskPlan/`：与知识章节一一对应的分章节执行计划。
- `TaskHistory/`：按日期归档每日已完成任务。
- `resouces/`：按知识章节归档图片、动图及完整外部资料文件。

## 当前状态

项目初始化阶段。知识正文将依据 `TaskPlan.md` 中的任务逐步研究、编写、交叉验证和维护。

## 贡献与真实性原则

所有可验证的技术事实应尽可能附带来源、版本和适用范围。未验证数据、工程估算、厂商宣传口径与实测结果必须明确区分，不得伪装为已确认事实。
