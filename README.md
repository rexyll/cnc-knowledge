## 仓库工作规则摘要

- 默认只在 `main` 分支开展所有操作；未经用户明确要求，禁止创建其他分支。
- 图片、动图及完整文档按知识章节归档在 `resouces/<章节目录>/`。
- 知识内容需注明来源、版本、适用范围和核验日期；不确定信息必须显式标注。
- 根目录 `TaskPlan.md` 的 Guide 和 Limit 是全库统一规则，章节计划默认继承。
