# 14. 性能指标、计量检测与验收

**English:** Performance, Metrology and Acceptance  
**范围：** 几何精度、定位精度、重复定位、动态特性、主轴性能、热特性、加工精度、可靠性及测试验收方法。

## 本章覆盖内容

- 几何精度、定位/重复定位精度、直线轴和回转轴检测
- 主轴转速/功率/转矩、振动、温升、跳动和动平衡
- 热变形、动态响应、轮廓精度、表面质量和加工能力
- 测试设备、测量不确定度、环境条件、验收标准和报告
