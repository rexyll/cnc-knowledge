# 06. 电气与电子系统

**English:** Electrical and Electronic Systems  
**范围：** 电气柜、供配电、保护、电机与执行器接线、传感器、继电器、接触器、I/O、电路板、电气原理图和电气安全接口。

## 本章覆盖内容

- 电源架构、配电、接地、屏蔽、短路/过载/漏电保护
- 控制柜布局、断路器、接触器、继电器、端子和线缆
- 传感器、编码器、限位开关、接近开关、温度/压力/流量检测
- 电气原理图、接线图、I/O表、线号、端子图和电气BOM
