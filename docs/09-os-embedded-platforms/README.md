# 09. 操作系统与嵌入式平台

**English:** Operating Systems and Embedded Platforms  
**范围：** 数控系统所使用的实时/通用操作系统、嵌入式硬件平台、启动链、实时调度、驱动框架和系统维护。

## 本章覆盖内容

- CNC控制器硬件平台、CPU/SoC、存储、总线和扩展接口
- 实时操作系统、嵌入式Linux、Windows平台及其应用边界
- 启动流程、固件、BSP、内核配置、设备树和系统服务
- 实时调度、时钟、中断、CPU隔离、内存和工业级可靠性
