# 11. 软件架构与接口设计

**English:** Software Architecture and Interfaces  
**范围：** 数控软件总体架构、模块边界、进程/线程、API、数据模型、配置、日志、诊断、升级和软件工程实践。

## 本章覆盖内容

- 数控软件分层、模块职责、控制数据流和状态管理
- 进程/线程模型、实时任务与非实时任务边界
- API、内部总线、共享内存、RPC、配置和数据持久化
- 测试策略、构建部署、版本管理、可观测性和软件维护
