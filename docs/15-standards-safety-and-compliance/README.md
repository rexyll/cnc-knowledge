# 15. 行业标准、安全与合规

**English:** Standards, Safety and Compliance  
**范围：** 数控机床相关国家/行业/国际标准、机械安全、电气安全、功能安全、EMC、环境要求和合规管理。

## 本章覆盖内容

- GB、JB/T、ISO、IEC、EN及相关标准体系和适用关系
- 机床机械危险、电气危险、急停、防护、联锁和风险评估
- 功能安全、安全相关控制系统、EMC和电气设备要求
- 标准状态、版本修订、适用范围、符合性评价和认证
