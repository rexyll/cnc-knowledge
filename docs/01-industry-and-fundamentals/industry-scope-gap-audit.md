# 数控机床知识库行业范围与章节边界审查

## 1. 审查目的与方法

本报告审查根目录总体计划、22章目录映射及各章任务计划中的目标和工作范围，重点检查：主题是否处于数控机床直接应用边界内；相邻章节是否出现职责重叠；跨章主题是否存在无人主责；行业地图是否被误当作技术内容完成；结构化实体和关系是否有明确归属。

本报告是项目范围治理与任务路由文件，不是新的技术知识文章，不创建KNOW实体，不增加实体、关系、来源或章节覆盖度计数。审查依据是仓库内现行计划和目录，不把尚未研究的技术事实写成已验证知识。

## 2. 总体结论

1. 现有22章总体上覆盖数控机床从整机、机械、电气、CNC、运动控制、通信、软件、工艺、检测、合规、制造、维护、故障、供应链、工程文档到数字化和案例的主要生命周期，暂未发现必须新增独立章节的主题。
2. 当前最需要治理的不是增加章节，而是明确相邻章节的“主问题”和交付物边界。跨章可互相引用，但一个知识对象应有一个权威主归属，避免重复建档。
3. CH01是行业导航与基础概念入口，不承担机型技术档案、零件数据库、标准解释或供应商目录的深度维护。
4. CH02负责机床类型和产品家族层面的技术认识；CH22负责选定具体参考机床后的整机级、配置级系统拆解。二者不能重复建设相同产品事实。
5. 当前结构化数据已登记KNOW、TERM、MTYPE、MACHINE、VENDOR、PRODUCT，但SUBSYS、PART、MAT、STD、INTERFACE、PROTO、SIGNAL、PARAM、APP等类型仍需按证据逐步建立。它们属于后续数据覆盖缺口，不代表这些知识主题在目录中完全缺席。
6. 现有覆盖矩阵CH01、CH02、CH19的统计口径应保持不变；范围审查报告不等同于新技术正文或新增已核验实体。

## 4. 主要交叉边界与统一处理规则

### 4.1 CH01 / CH02 / CH19：行业、类型、供应商三层分离

- CH01只回答行业边界、角色和分类导航；分类体系的详细机床类型定义由CH02维护。
- CH02的MACHINE/产品样本描述机型类别或代表性产品；厂商身份、官方产品线和供应关系由CH19维护。
- 任何厂商“拥有/生产/供应”关系必须由明确来源证明；文章索引边不能替代事实关系。

### 4.2 CH02 / CH22：产品家族与具体整机实例分离

- CH02描述某类机床或产品系列的共性和差异，不复制每一台参考机床的配置清单。
- CH22只选择有公开资料支撑的具体机型/配置，记录其实际系统组成和证据；未知选配项不得推定。
- 一个具体型号若同时出现在CH19产品目录和CH22案例中，实体主记录保持唯一，案例使用链接与配置上下文。

### 4.3 CH03～CH08：物理系统与控制职责分层

- CH03维护整机机械结构和机械接口；CH04维护零件、材料和制造属性；CH05维护刀具/工装/装夹；CH06维护电气供电、保护、传感器和I/O硬件；CH07维护CNC/PLC功能与顺序逻辑；CH08维护驱动、电机和反馈闭环。
- 同一子系统可被多章引用，但主记录按其主要工程属性归属；例如刀库机械结构归CH03，刀库控制顺序归CH07，刀库型号/供应商归CH19。

### 4.4 CH07～CH12：控制器、平台、传输、软件与算法分层

- CH07描述数控产品的控制功能与PLC职责；CH09描述承载软件的计算平台和OS机制；CH10描述设备间通信协议；CH11描述应用软件内部架构和接口；CH12描述控制/加工算法的数学与实时实现。
- “EtherCAT驱动器状态机”可由CH10解释协议状态与过程数据，由CH08解释驱动器控制职责，由CH07说明CNC/PLC调用关系；不应复制成三份互相矛盾的主文档。
- 实时调度是CH09的OS机制；实时任务架构/线程设计归CH11；插补和速度规划的算法约束归CH12。

### 4.5 CH12～CH15：算法、工艺、检测与规范分层

- CH12回答轨迹如何计算；CH13回答如何为工件选择工艺、刀具和刀路并生成程序；CH14回答如何测量加工结果与设备性能；CH15回答适用规范、风险和符合性要求。
- 标准规定的检测项目或方法可在CH14建立操作性摘要，但标准编号、版本、适用范围和状态以CH15为唯一主记录。
- 工艺参数不等于控制算法参数；测量值不等于产品标称值或验收限值。

### 4.6 CH16～CH18：生命周期阶段分离

- CH16覆盖制造、装配、安装、初次调试和交付；CH17覆盖正常使用、计划维护和授权维修；CH18覆盖故障机理、诊断证据和可靠性方法。
- 故障案例可以在CH18建立根因分析主条目，在CH17引用其维修工单/更换步骤；不能把推测根因写成已确认故障。
- 所有危险作业遵循CH15与具体设备手册，章节划分不降低安全要求。

### 4.7 CH19～CH22：供应商、工程文档、数字化和案例分离

- CH19维护组织与产品身份及官方资料；CH20维护配置结构和文件元数据；CH21维护机床数据与工厂信息系统集成；CH22维护具体参考机床实例。
- 产品规格书的文档元数据归CH20，厂商/产品事实归CH19，机型应用语境归CH02或CH22。
- 机床联网到MES属于CH21；设备内CNC/PLC到驱动的实时总线属于CH10。二者接口可关联，但不能混淆实时控制网络和上层生产信息网络。

## 6. 需要修订的任务执行约束

1. 不新增第23章；通过主归属、交叉链接和结构化实体类型扩展覆盖。
2. 后续每个章节首个数据任务必须先定义本章实体字段和主归属，再录入样本；避免先堆实体后返工。
3. 跨章关系需区分“事实关系”“文章索引关系”和“引用/映射关系”，并为事实关系提供来源；不得把DERIVED_FROM文章索引当作工程关系。
4. 对多章主题指定一个主文档，其余章节写本章视角的差异与链接，不复制整篇内容。
5. 产品、供应、兼容、替代、标准符合性和性能数据均需有适用型号/配置、版本和来源，不能从系列名或厂商宣传推断。
6. 本次审查没有新增技术实体、来源或媒体资源，因此不变更实体/关系/资源计数，也不提升CH01覆盖等级。

## 8. 审查限制
