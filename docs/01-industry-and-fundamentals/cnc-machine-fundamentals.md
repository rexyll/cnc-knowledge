# 数控机床基本原理、坐标系与运动链

## 1. 范围与边界

数控机床（Computer Numerical Control machine tool，CNC machine tool）以数字化程序指令控制刀具与工件之间的相对运动，并按机床配置执行主轴、换刀、夹紧、冷却和排屑等辅助功能。加工结果来自“程序描述—运动规划—驱动执行—机械运动—刀具/工件相互作用”的完整链条，而不是单独由CNC控制器决定。

本文建立通用工程概念，不替代具体机床的操作手册、CNC编程手册、电气图纸和安全规程。坐标系名称、轴配置、通道分配、回零方式、补偿参数及可用功能均可能随机床结构、控制系统品牌、软件版本和选件变化。ISO 841规定数控机床坐标系与运动命名的基础框架；ISO 2806提供数控相关术语。引用标准时应按具体版本和适用范围使用，不把标准词汇与某一厂商的界面标签混为一谈。〔SRC-000027，ISO 841:2001〕〔SRC-000028，ISO 2806:1994〕

## 2. 从NC程序到加工运动：基本工作链

典型数控加工链为：

CAD/CAM或手工编程 → NC程序 → 程序管理与解释 → 轨迹规划/插补 → 坐标变换与补偿 → 各轴设定值 → 伺服驱动与电机 → 机械传动和运动部件 → 刀具与工件的相对运动。

概念化结构（实际产品可能将多个模块集成在同一软硬件平台中）：

    HMI / 程序管理 / 操作界面
                 │ NC程序、操作指令
                 ▼
    NC核心：解释/预处理 → 前瞻与轨迹规划 → 插补 → 坐标变换/补偿
                 │ 位置/速度等轴设定值
                 ▼
          伺服驱动器与电机
                 ▼
      丝杠/齿轮/直驱、导轨、滑台、
      主轴头、工作台和回转部件
                 ▼
             刀具—工件过程
                 ▲
                 │ 位置/速度反馈
      编码器、光栅尺、角度编码器
                 └────反馈至控制环

    PLC/机床逻辑：换刀、夹紧、冷却、润滑、排屑、辅助时序等

### 2.1 HMI、NC核心与PLC

一种常见的功能分解将CNC系统分为HMI、NCK（Numerical Control Kernel）和PLC：HMI负责人机交互，NCK管理连续轨迹和运动控制，PLC负责顺序逻辑及离散辅助动作。同行评审综述采用了这一概括，但它不是所有控制器的强制硬件划分；不同厂商可能采用软硬件集成、不同命名或不同模块边界。〔SRC-000034，§2.1〕

- **HMI（Human-Machine Interface）**：显示状态、编辑/选择程序、设置工件和刀具数据、显示报警并接收操作命令。
- **NC核心/NCK**：解释NC程序中的运动指令，计算轨迹及轴运动设定值，并管理插补、坐标变换和相关补偿。
- **PLC（Programmable Logic Controller）**：执行机床顺序控制和辅助逻辑，例如换刀流程、夹具动作、冷却泵、润滑、排屑和状态联锁。
- **驱动与反馈系统**：把轴设定值转换为电机电流、转矩和运动，并把编码器或直线测量系统反馈给控制环。
- **安全相关控制**：急停、防护门、安全限位、STO等安全功能应由经设计和验证的安全相关系统承担；普通PLC逻辑不天然等同于满足功能安全要求的控制系统。

### 2.2 运动设定值与机械执行

控制器根据坐标系、刀具/工件偏置、机床运动学和补偿数据，将编程轨迹映射到各受控轴的设定值。驱动器和电机产生运动，经滚珠丝杠、齿轮、联轴器或直驱机构传递到滑台、主轴头、转台或工作台。

反向间隙、弹性变形、摩擦、热变形、几何误差和动态响应都会影响实际运动。这些误差需要由机械设计、装配校准、控制参数和补偿方法共同管理，不能只靠提高插补精度消除。

## 3. 坐标系、零点和参考点

坐标系回答两个问题：程序中的坐标相对于什么基准定义？控制器如何将该基准转换成机床各轴的实际运动？ISO 841是理解机床坐标和运动命名的主要通用依据。具体控制器可能在MCS、WCS之外定义基本坐标系、设置坐标系、刀具坐标系或工作平面坐标系等层次。〔SRC-000027〕〔SRC-000029，§3.1〕〔SRC-000030，§15.1〕

### 3.1 机床坐标系（MCS）

机床坐标系（Machine Coordinate System，MCS）是以机床制造商定义的机床基准建立的坐标系统，用于表达机床各物理轴的位置。机床零点通常由机床制造商定义，其具体位置与机床结构、轴配置和参数设定有关。MCS是机床侧基准，不应与工件装夹所使用的编程原点混淆。〔SRC-000027；SRC-000029，§3.1.1〕

### 3.2 工件坐标系（WCS）与工件零点

工件坐标系（Workpiece Coordinate System，WCS）用于针对特定工件或装夹建立编程基准。工件零点是该坐标系的原点，可依据工件基准面、孔、边或测量结果设置。NC程序中的几何坐标通常相对于所选工件坐标系解释，再经偏置和坐标变换映射到机床坐标系。

例如，SINUMERIK编程资料以G54、G55等作为可设定工件偏置的实例；这些代码及其细节应按具体CNC系统编程手册核对，不能推断所有控制系统完全相同。HEIDENHAIN TNC7还定义了工作平面等坐标系层级，说明不同平台对变换链的命名和组织方式可以不同。〔SRC-000029，§3.1.4〕〔SRC-000030，§15.1〕

### 3.3 机床零点、工件零点与参考点不能互换

| 名称 | 英文 | 含义 | 使用注意 |
|---|---|---|---|
| 机床零点 | Machine zero | MCS的机床基准原点，由机床制造商定义 | 不一定位于行程端部，也不等同于回零开关位置 |
| 工件零点 | Workpiece zero / datum | 特定工件坐标系的原点 | 随装夹、工序和工件基准选择而变化 |
| 机床参考点 | Machine reference point | 用于建立或恢复轴坐标基准的已知位置 | 具体由编码器、参考标记、开关、挡块或组合方法实现，依机型而定 |
| 当前轴位置 | Actual axis position | 控制器依据反馈和坐标关系报告的轴位置 | 需要结合坐标系、偏置和反馈位置理解 |

“回参考点/回零”（homing/reference return）是建立轴位置基准的过程，不意味着机械运动一定返回机床零点本身。设备可能把参考点设置在便于检测且可重复定位的位置；参考点与机床零点之间的关系由机床参数和制造商配置确定。操作前必须查阅对应机型的回参考点说明，不能把不同机床的回零开关位置或操作步骤直接套用。〔SRC-000029，§3.1.1–3.1.3〕〔SRC-000030，§7.1〕

### 3.4 坐标变换与刀具/工作平面坐标

当工件装夹方向、工作台角度或刀具姿态与机床基础坐标不一致时，控制器可能使用设置偏置、平移/旋转变换、刀具坐标或运动学变换，将编程坐标转换到实际轴坐标。五轴机床尤其需要区分编程坐标、刀尖点/工件坐标、旋转轴中心和机床轴坐标。变换名称、矩阵方向、调用方法和RTCP等功能均依具体机床与CNC选项确定；本文不提供可直接用于任意设备的参数设置步骤。〔SRC-000029，§3.1〕〔SRC-000030，§15.1〕〔SRC-000032，chapter 5〕

## 4. 机床轴系命名与轴数

### 4.1 直线轴和回转轴命名

ISO 841的通用命名体系以右手笛卡尔坐标框架描述主要直线运动轴：
- **X、Y、Z**：主要直线轴，分别沿坐标系三个相互正交的方向。
- **A、B、C**：分别绕X、Y、Z轴的回转运动。
- **U、V、W**：与X、Y、Z平行的第二组直线轴名称，常用于表示附加的平行轴。

这些字母描述运动轴与坐标系的关系，不直接说明究竟是刀具、主轴头、工作台还是工件在物理上移动。判断方向和正负号时，应结合ISO命名约定、机床布局图和该设备的制造商定义。〔SRC-000027〕〔SRC-000030，§7.1〕

### 4.2 轴数、可控轴数和同时联动轴数

工程沟通中至少要分清：
1. **物理运动轴**：机器上实际存在的直线或回转运动机构。
2. **可控轴/配置轴**：控制系统可以识别和控制的轴，可能包括主运动轴、附加定位轴和PLC控制轴。
3. **通道/路径轴**：在特定控制平台与通道中被分配参与路径插补的轴。
4. **同时联动轴数**：在同一时段受同一轨迹规划/插补关系协调控制的轴数量。

所以“5轴机床”并不自动证明所有五个轴能在同一通道内同时进行任意五轴联动；也不代表旋转轴、直线轴和主轴共享完全相同的动态或插补能力。选型时应查清受控轴总数、通道数、每通道可用的路径轴、同时插补能力、PLC轴能力、选件和软件版本。

SINUMERIK MC功能手册明确区分路径插补轴与可独立插补的定位轴；定位轴可按PLC控制等方式运行。这是该控制平台的具体实现示例，不应作为所有品牌的统一定义。〔SRC-000031，§6.3〕〔SRC-000032，chapter 4〕

## 5. 运动链与运动学

运动链（Kinematic chain）是从机床基础件、驱动和传动机构，经导轨/滑台、立柱/主轴头或工作台/转台，最终到刀具与工件的运动连接关系。它体现“哪一个部件相对哪一个部件运动”，也是建立机床运动学模型和坐标变换的物理基础。

典型直线进给链：

伺服电机 → 联轴器/减速机构（如有） → 滚珠丝杠或直驱机构 → 螺母座/滑台 → 直线导轨 → 刀具侧或工件侧结构。

回转轴可能通过力矩电机、蜗轮蜗杆、齿轮传动或其他机构驱动转台/摆头。实际配置必须以机型结构图和BOM为准。多轴机床的运动学链包含串联或并联的平移/旋转部件，坐标变换必须按照真实拓扑建立；不能只依据机床名称推断轴中心、旋转顺序或RTCP计算模型。SINUMERIK功能手册中设有运动学链配置章节，说明机床结构与控制器运动学定义之间存在明确映射关系。〔SRC-000032，chapter 5〕

## 6. 插补、轨迹规划与伺服反馈

### 6.1 插补与轨迹执行

插补（Interpolation）根据程序给定的几何路径、进给条件和轴运动学，计算控制周期内各轴应到达的中间位置/运动设定值。常见路径形式包括直线、圆弧和样条等；具体支持的曲线类型、精度和解释规则依控制系统及软件版本而定。路径规划还要处理速度、加速度、加加速度（jerk）、拐角过渡、轴限值及前瞻等因素。〔SRC-000031，§6.3〕〔SRC-000032，chapter 6〕

### 6.2 伺服控制的基本层次

伺服控制把NC生成的轴设定值转换为电机输出，并通过反馈降低跟踪误差。典型系统可能包含电流/转矩环、速度环和位置环，但各环的实现位置、带宽和控制器分工取决于驱动器与CNC架构。

以SINUMERIK MC功能手册中的轴控制结构为例，驱动侧包含电流环和速度环，NC侧执行较高层的位置控制；手册也展示路径插补、细分插补、滤波和位置控制等模块。此处是具体平台实现例子，不意味着所有CNC均以相同方式分配闭环。〔SRC-000031，§2.5〕

### 6.3 半闭环与全闭环位置反馈

- **半闭环（semi-closed-loop）**：使用电机端旋转编码器作为位置反馈。编码器测量电机转角，再结合传动参数估算滑台位置；丝杠、联轴器和传动链在编码器之后产生的误差通常不会被该位置测量直接覆盖。
- **全闭环（full-closed-loop）**：使用安装在直线运动部件上的光栅尺/直线编码器，或回转轴上的角度编码器直接测量工作台/滑台/转台位置，使更长一段机械传动链进入位置反馈测量范围。

HEIDENHAIN对两种方案的说明强调反馈测量点的差异：电机端编码器不能直接感知其后传动机构的全部误差，直接测量滑台或回转轴位置则把更多机械环节纳入测量。选择方案还要综合机床结构、成本、安装维护、热稳定性、机械误差、反馈分辨率和控制稳定性；不能把某一种方案描述为在所有机型上都绝对更优。〔SRC-000033，Position acquisition on linear axes〕

## 7. 常用术语速查

| 术语 | 英文/缩写 | 核心含义 | 注意事项 |
|---|---|---|---|
| 机床坐标系 | MCS | 由机床侧基准定义的物理轴坐标 | 零点由机床制造商定义 |
| 工件坐标系 | WCS | 针对特定工件/装夹的编程坐标 | 工件零点随工序和装夹设定 |
| 机床参考点 | Machine reference point | 用于建立轴坐标基准的已知位置 | 不等同于机床零点 |
| 直线轴/回转轴 | Linear/rotary axis | 沿坐标方向移动/绕坐标轴转动 | 命名与物理移动部件需区分 |
| 插补 | Interpolation | 沿目标路径计算协调的轴运动设定值 | 不等同于伺服电流控制 |
| 路径轴 | Path axis | 特定CNC通道内参与路径插补的轴 | 术语与能力需按平台确认 |
| 运动链 | Kinematic chain | 机床运动部件之间的连接与相对运动关系 | 需要真实结构拓扑 |
| 半闭环/全闭环 | Semi-/full-closed loop | 由电机端/负载端反馈测量位置的方案 | 判断关键是测量位置而非名称 |

术语的完整定义、中英文映射和来源记录见[全库术语表](../GLOSSARY.md)，对应结构化术语记录位于docs/data/entities/TERM/。

## 8. 工程使用中的核对清单

理解或集成某台具体机床前，至少核对：
- 各物理轴名称、运动方向、行程范围及其在控制器中的轴号/通道分配。
- 机床零点、参考点、回参考点流程和各轴反馈元件的位置。
- 工件坐标、刀具坐标、机床坐标及其偏置/变换的层级与生效顺序。
- CNC通道、路径轴、独立定位轴、PLC轴和主轴的分配与同时联动能力。
- 插补、前瞻、加减速、jerk限制和旋转轴/刀尖点控制等功能是否具备，以及是否受选件和软件版本限制。
- 伺服反馈结构、机械传动形式、补偿项和测量校准依据。
- PLC辅助逻辑与经验证的安全相关控制系统之间的职责边界。

本文不包含可直接复制到不同机床的参数值或操作步骤。涉及回参考点、刀具/工件偏置、轴参数、伺服增益、联锁或安全功能的修改，必须由具备资质的人员依具体机床制造商手册、现场风险评估和安全程序进行。
