# 16. 制造、装配、安装与调试

**English:** Manufacturing, Assembly, Installation and Commissioning  
**范围：** 机床制造流程、精密装配、安装基础、运输就位、精度恢复、电气接线、上电、调试和交付。

## 本章覆盖内容

- 整机制造流程、零件质量、装配基准和工序控制
- 导轨/丝杠/主轴/转台装配、预紧、润滑和精度调整
- 运输、地基、找平、环境、电源、气源、冷却和排屑安装条件
- 上电检查、参数恢复、轴调试、几何检测、试切和交付验收
