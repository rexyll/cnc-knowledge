# 21. 数字化、联网与智能制造

**English:** Digitalization, Connectivity and Smart Manufacturing  
**范围：** 数控机床联网、数据采集、状态监测、工业信息模型、MES/ERP集成、能耗、预测性维护、数字孪生和网络安全。

## 本章覆盖内容

- 机床数据采集、实时/非实时数据、报警、工艺和生产数据
- OPC UA、MTConnect、MQTT及制造信息模型和互操作
- MES、ERP、SCADA、DNC、工厂网络和边缘计算集成
- 设备健康、能耗、质量追溯、预测性维护和数字孪生
- 工业网络安全、资产盘点、分区隔离、身份认证和补丁管理
