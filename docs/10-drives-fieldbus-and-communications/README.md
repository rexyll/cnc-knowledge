# 10. 驱动、现场总线与工业通信

**English:** Drives, Fieldbus and Industrial Communications  
**范围：** 驱动接口、工业以太网、现场总线、实时通信、设备配置、网络拓扑、诊断和互操作。

## 本章覆盖内容

- EtherCAT、PROFINET、PROFIBUS、CAN/CANopen、Modbus等
- 实时以太网拓扑、主站/从站、时钟同步、周期通信和诊断
- CNC、PLC、驱动、I/O、传感器和上层系统的数据接口
- 网络配置、设备描述文件、总线诊断和互操作测试
