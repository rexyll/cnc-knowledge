# 典型数控机床产品与型号规格目录

## 1. 目录定位与数据口径

本目录从制造商公开产品页和规格资料中选取代表性整机型号，提供型号检索、类型归属、规格定位和配置核验入口；不是全球型号全集、市场份额榜单、采购推荐或性能排名。

- “官方型号/产品页”表示制造商公开页面明确列出该产品或系列。
- “厂商声明参数”来自制造商页面/规格书，不等同于第三方测试或本项目实测。
- 系列参数不得套用到该系列每一个子型号；仅记录页面中明确对应型号行的数值。
- 标准配置、选配、订货配置和地区版本分开记录；未明确的信息标注待核实。
- 本轮核验日期为2026-11-22；在线页面可能更新，后续应记录版本/日期并审查差异。

## 3. 型号级公开规格

### 3.1 Okuma GENOS M560-V（OSP-P500配置）

原厂产品页列出最大加工范围1,050×560×460 mm，工作台1,300×560 mm，主轴转速15,000 min⁻¹，主轴电机功率22/18.5 kW，快速移动X/Y 40 m/min、Z 32 m/min，刀库32把。页面明确注明该组规格对应OSP-P500配置。〔SRC-000044；SRC-000013〕

**重要区分：** GENOS M560-V与GENOS M560V-5AX是不同的配置/型号表达。后者另有A/C轴、回转工作台等数据；不能把5AX规格混入普通M560-V记录。

### 3.2 Mazak INTEGREX i-200 NEO / i-200S NEO

原厂系列页说明INTEGREX i NEO集成车削与铣削。页面列出的i-200 NEO为8英寸卡盘、最大加工直径Φ600 mm、最大加工长度590 mm、Y轴行程210 mm；i-200S NEO为第二主轴版本，页面列出最大加工长度850 mm。系列页面也说明铣削主轴有不同转速/功率组合，具体值按子型号和选件区分。〔SRC-000045〕

**配置边界：** i-200、i-200S、i-200ST不是同一配置。第二主轴、下刀塔、铣削主轴和控制选件必须按订货规格逐项确认；不能将“系列可提供”写成每台设备标配。

### 3.3 Mazak QUICK TURN 200MSY

原厂型号表列出QUICK TURN 200MSY：8英寸卡盘、最大加工直径Φ14.75英寸、最大加工长度22.70英寸；该型号行标示铣削、第二主轴和Y轴配置。〔SRC-000046〕

这些数值只对应QUICK TURN 200MSY型号行。系列页面所述C轴最小分度、主轴、测量反馈和自动化能力仍需区分标准/选配及具体子型号。

### 3.4 DMG MORI DMU 50 3rd Generation

原厂页面列出X/Y/Z行程650/520/475 mm，最大工件直径630 mm、高度600 mm、质量300 kg，并描述摆动回转工作台用于五轴同时加工。主轴转速、功率和刀库容量存在基础配置与选项差异，不能把系列最高值当作标准配置。〔SRC-000047〕

### 3.5 TRUMPF TruLaser 3030 fiber

原厂页面列出X/Y工作范围3,000×1,500 mm、基本机重量11,700 kg、最大同时速度170 m/min。激光功率和不同材料最大板厚依激光器型号、材料及工艺包配置变化，不得脱离配置单独引用。〔SRC-000048〕

## 5. 结构化数据与关系语义

MACHINE实体用于记录整机型号，受控关系如下：

- `MODEL_OF`：MACHINE → MTYPE，表达本库中的机床类型归属。
- `MANUFACTURED_BY`：MACHINE → VENDOR，表达制造商身份。
- `DERIVED_FROM`：KNOW → MACHINE，仅表示本目录导航和溯源，不代表额外配置、兼容、供货或性能事实。

型号记录保留manufacturer_id、model_code、machine_type_id、轴配置、布局、工艺能力、配置选项、公开规格、规格版本/核验日期及source_ids。公开参数逐项带单位和来源ID。

## 6. 型号选型必须核验的项目

1. **产品身份：** 完整型号代码、代际、地区版本、生命周期和制造商。
2. **加工能力：** 工件最大尺寸/质量、行程、主轴/激光器/砂轮能力和工艺范围。
3. **轴与运动：** 可控轴、同时联动轴、旋转轴结构/摆角、定位与插补能力；“五轴”标签不能代替轴配置表。
4. **配置：** 主/副主轴、刀塔、刀库、转台、托盘交换、测头、自动化、控制器、冷却/排屑等标准与选配项。
5. **性能证据：** 区分厂商目录参数、合同规格、第三方测试和现场验收实测；精度与节拍需有测试方法和工况。
6. **交付与维护：** 当前地区供货、服务授权、备件、软件版本和升级政策需向当地原厂/授权渠道确认。本目录不声明价格、库存或交期。
