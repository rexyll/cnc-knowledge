# 数控机床选型方法与工程比较矩阵

## 1. 目的与原则

本指南建立从工件和工艺需求出发的机型筛选、比较、证据核验和采购验收输入方法。它不是品牌排名或采购建议，也不替代工艺验证、风险评估、原厂规格书和合同验收。

选型顺序：明确工艺路线 → 建立工件/产量/质量输入 → 执行硬性门槛检查 → 选择候选机型 → 同口径比较配置与证据 → 代表性工件试切 → 关闭风险并形成验收条款。

不可用单一指标（主轴最高转速、快速移动速度、轴数、定位精度或价格）代替整机适用性判断。

## 2. 需求输入清单

| 维度 | 必须澄清的问题 | 记录内容 |
|---|---|---|
| 工件身份 | 图号/版本、材料与状态、毛坯形式？ | 图纸、材料牌号/热处理、毛坯余量 |
| 几何包络 | 最大外形、长度/直径、深孔、薄壁、曲面？ | 尺寸、装夹后空间、刀具可达性 |
| 质量与装夹 | 工件和夹具总质量、重心、夹紧方式？ | 质量、偏载、重心、夹紧/支承 |
| 工艺路线 | 车、铣、钻、镗、磨、齿轮或特种加工？ | 工序卡、基准转换、工序数量 |
| 质量要求 | 尺寸/形位公差、粗糙度、批间一致性？ | 公差、测量方法、环境和工况 |
| 产量 | 年需求、批量、班次、换型频率？ | 节拍、换型时间、产能假设 |
| 自动化 | 是否需要棒料、托盘、机器人、在线测量？ | 接口、装卸节拍、缓冲和安全 |
| 现场 | 占地、地基、供电、气源、冷却、排风、排屑？ | 布局、公用工程容量、安装条件 |
| 生命周期 | 服务、备件、培训、软件许可和升级？ | 服务区域、备件策略、维护能力 |

信息不足时记录假设和待澄清项，不通过主观评分掩盖需求缺口。

## 3. 工艺路线与机型初筛

| 工件/加工特征 | 优先考察的机型 | 需比较的替代路线 |
|---|---|---|
| 轴、盘、套类回转体 | 数控车床/车削中心 | 车铣复合、自动车床、磨床；看长径比、夹持和二次装夹 |
| 箱体、板类、多面孔系 | 立式/卧式加工中心 | 龙门、镗铣、五轴；看承载、基准转换、排屑和刀具可达性 |
| 叶轮、叶片、自由曲面 | 五轴加工中心 | 3+2定位加工或多工序组合；核对同时联动和刀轴控制 |
| 车削+偏心孔/端面铣 | 车铣复合/多任务机床 | 车削中心+加工中心；比较一次装夹收益和复杂设备成本 |
| 高精度平面/外圆/内孔 | 对应磨削/精整机床 | 精密车削/铣削后精加工；核对余量、热处理和测量 |
| 齿轮齿形/齿面 | 滚齿/插齿/磨齿专机 | 通用加工或车齿路线；结合齿轮类型、模数、精度和批量 |
| 薄板二维轮廓 | 激光/水射流/冲剪等 | 等离子/机械冲裁；比较材料、厚度、热影响和后处理 |
| 高硬材料/窄缝/型腔 | EDM/电化学/激光/超声 | 组合工艺；核对导电性、表面完整性、效率和耗材 |

“优先考察”只是工艺初筛，不代表具体设备能力保证；材料、工艺规范、刀具和质量要求可能改变路线。

## 4. 硬性门槛（Gate）

任何关键门槛不满足，候选方案不得进入加权排名；应判不合格或待澄清。

1. **尺寸与可达性：** 工件和夹具在所有加工姿态下满足行程、回转空间、刀具伸出、换刀及干涉要求；不能只比较名义轴行程。
2. **承载与夹紧：** 工作台/卡盘/托盘允许质量、偏载、重心、夹紧力和支承条件满足工件及工装总成。
3. **工艺能力：** 主轴功率/转矩曲线、转速范围、刀具接口、激光器/砂轮/电极等工艺单元适合实际材料和负载。
4. **轴系：** 分清物理轴、数控可控轴、同时联动轴、旋转轴摆角/速度/承载和RTCP等功能；“五轴”标签不能代替轴配置表和试件验证。
5. **质量：** 对目标公差提供测试方案、工件/试件条件、测量设备和验收判据；缺证据时标记待验证。
6. **安全合规：** 防护、联锁、激光/高压/高速旋转/粉尘烟尘风险符合适用法规、设备手册和现场EHS要求。
7. **现场条件：** 地基、吊装通道、供电、气源、冷却、排风、排屑、消防和温控满足安装条件。
8. **服务能力：** 关键备件、授权服务、软件许可、远程支持边界和维修能力得到书面确认。

## 5. 加权比较矩阵

### 5.1 初始权重模板

先执行Gate，再对合格候选设备按1～5分评价。以下权重是通用项目的**初始工程模板**，不是行业标准；应按项目特点调整并记录理由。

| 评价维度 | 权重 | 评价要点 |
|---|---:|---|
| 工艺匹配与覆盖度 | 20% | 关键工序、刀具可达性、基准转换、工序合并 |
| 工件包络与承载 | 15% | 工件/夹具尺寸质量、干涉空间、装夹与排屑 |
| 加工质量与精度证据 | 20% | 试切、几何/定位/热/动态测试、过程稳定性 |
| 产能与节拍 | 15% | 完整循环、换刀/换托盘、装卸、换型和停机 |
| 柔性与扩展性 | 10% | 产品族、工艺变更、自动化接口、控制扩展 |
| 全生命周期成本 | 10% | 购置、工装、安装、能耗、耗材、维护、停机、残值 |
| 维护与服务能力 | 5% | 诊断、响应、备件、培训、维护复杂度 |
| 占地与公用工程 | 5% | 设备/外围面积、基础、供电、冷却、排风 |
| **合计** | **100%** | |

### 5.2 评分尺度

| 分值 | 定义 | 证据要求 |
|---:|---|---|
| 1 | 不满足或风险不可接受 | 关键缺口、负面试验或Gate失败 |
| 2 | 勉强满足 | 依赖额外工装/工序或高风险假设 |
| 3 | 基本满足 | 规格和初步工艺分析支持，仍需验证 |
| 4 | 匹配较好 | 目标工件试验或等效证据支持 |
| 5 | 高度匹配 | 代表性工件、产能和质量验证充分 |
| N/V | 未验证 | 缺少足够证据，不得默认记为3分 |

评分是需求匹配度与证据强度的综合判断，不能只按厂商宣传给高分。若关键项N/V，应标记“待验证”，不能静默归一化剩余权重后宣布胜出。

### 5.3 计算

设权重为 (w_i)（百分数），评分为 (s_i)（1～5）：

\[
S=\sum_i \frac{w_i}{100}s_i
\]

总分范围1～5。必须同时展示分项分数、证据类型、N/V项和风险，不能只显示总分。

## 6. 精度与质量：按测试对象比较

精度数字必须带测试方法、配置、环境、热状态、测量设备、工件/试件和统计口径。标准入口如下：

- **ISO 230-1:2012**：无负载或准静态几何精度测试；不等于动态切削能力，也不覆盖振动、爬行或速度/进给特性。
- **ISO 230-2:2014及Amd 1:2016**：数控直线轴和旋转轴定位精度与重复性；不能单独代表成品加工精度。
- **ISO 10791-7:2020**：加工中心标准试件切削精度测试，范围覆盖与测试配置兼容的3～5轴同时加工。
- **ISO 13041-6:2009**：数控车床/车削中心标准试件切削精度测试。

至少分开核验：几何精度、数控轴定位/重复性、热效应、圆度/轮廓/动态性能，以及代表性工件试切和过程能力。不同标准工况下的结果不能直接横向排名；几何精度值不能直接换算为成品公差。

## 7. 产能、成本与风险

### 7.1 完整循环时间

\[
T_{cycle}=T_{cut}+T_{tool}+T_{load}+T_{probe}+T_{aux}+T_{wait}
\]

分别表示切削、换刀、装卸、测量、辅助动作和等待时间。多工序设备应考虑并行动作、工件交换、刀具寿命、清屑和上下游缓冲。产能估算还需说明换型、设备可用率、性能损失、质量损失和维护停机；OEE只有在统计口径一致时才可比较。

### 7.2 全生命周期成本（TCO）

\[
TCO=C_{purchase}+C_{tooling}+C_{installation}+C_{energy}+C_{consumables}+C_{maintenance}+C_{downtime}-V_{residual}
\]

比较周期、产量、折现率、能源价格、维护边界和残值假设必须一致。缺少报价、能耗实测、维修记录或停机损失数据时，标记待询价/待测量，不虚构成本。

\[
C_{good\ part}=\frac{TCO_{period}}{N_{good\ parts}}
\]

分母应为合格件数量，而不是理论加工件数。

### 7.3 风险台账

| 风险 | 典型问题 | 证据/控制 |
|---|---|---|
| 工艺 | 材料/刀具不适配、变形、毛刺、热影响 | 试切、工艺评审、测量报告 |
| 精度 | 热漂移、装夹变形、轴间误差 | 热稳定性和代表性工件测试 |
| 配置 | 关键选件遗漏、地区版本差异 | 订单BOM、配置清单、合同附件 |
| 产能 | 换刀/装卸/排屑成为瓶颈 | 完整循环测时、连续生产验证 |
| 维护 | 专用备件、服务距离、诊断工具受限 | 服务SLA、备件清单、培训 |
| 交付 | 地基、公用工程、吊装条件不满足 | 现场勘查、安装条件确认 |
| 生命周期 | 型号停产、软件升级、备件替代困难 | 生命周期声明、替代策略 |

## 8. 典型决策案例（方法示例，非品牌排名）

### A. 轴类零件、批量较大
候选：数控车削中心；有偏心孔/端面铣时再考察动力刀塔、Y轴或副主轴配置，也可比较车铣复合。重点核验棒料通径、夹持长度、长径比、主副轴交接、排屑、刀具寿命和自动上下料。用真实材料、毛坯、夹具连续试制，统计合格率、停机和单位合格件时间。

### B. 箱体/复杂壳体、多面加工
候选：立式/卧式加工中心、四轴/五轴加工中心或专用工装路线。比较装夹次数、基准转换、工件承载、刀具可达性、排屑、托盘交换、占地和夹具成本。五轴能力必须核对同时联动、刀轴可达性及碰撞验证。

### C. 高精度齿轮/精密表面
候选：滚齿、插齿、磨齿等专用设备，并结合热处理、测量和精整工序。核验齿轮类型、模数/齿数、齿宽、材料状态、精度等级、砂轮修整和测量闭环。通用加工中心的几何精度不能替代齿轮工艺能力。

### D. 薄板二维轮廓
候选：光纤激光、冲剪、等离子或水射流。比较材料牌号、厚度、热影响、边缘质量、耗材、烟尘/废液处理、上下料和后处理。激光功率不能单独决定板厚和质量，须按实际材料试样测量。

## 11. 来源与证据边界

- 〔SRC-000049〕ISO 230-1:2012：无负载/准静态几何精度测试。
- 〔SRC-000050〕ISO 230-2:2014及Amd 1:2016：数控轴定位精度和重复性。
- 〔SRC-000051〕ISO 10791-7:2020：加工中心试件加工精度。
- 〔SRC-000052〕ISO 13041-6:2009：数控车床/车削中心试件加工精度。

标准来源只用于界定测试方法入口，不表示任何型号已经符合标准。权重、评分尺度、产能/TCO模型和案例是可调整工程方法，不是ISO规定。采购验收前应核验标准现行状态、适用范围、合同引用版本及标准全文。

> 规格必须对应具体型号、地区和订货配置。涉及吊装、激光、高压、高速旋转、夹紧和维护作业，须由合格人员按设备手册、适用法规及现场LOTO/EHS程序执行，不得旁路防护或联锁。
