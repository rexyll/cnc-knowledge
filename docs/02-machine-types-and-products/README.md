# 02. 数控机床分类与产品

**English:** Machine Types and Products  
**范围：** 数控车床、铣床、加工中心、磨床、齿轮加工、特种加工、复合加工及专用机床的分类、结构和产品特征。

## 本章覆盖内容

- 按加工方法、运动形式、结构布局、轴数、用途和自动化程度分类
- 车削、铣削、钻镗、磨削、齿轮加工、线切割/电火花等机型
- 立式/卧式、龙门、五轴、车铣复合、专用及生产线机床
- 典型型号、配置、性能范围、选型维度和适用工艺
