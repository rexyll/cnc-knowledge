# 数控机床分类体系与产品型号索引

> 知识ID：KNOW-000003  
> 主章节：CH02  
> 核验日期：2026-11-22  
> 分类模型：多维分类；版本1.0

## 1. 分类原则

机床分类至少要区分四类不同问题：

1. **加工过程**：机床主要通过何种加工原理去除材料或使材料成形？
2. **结构布局**：主轴、工作台、立柱、滑枕、转台和工件如何布置？
3. **运动与控制能力**：有多少可控轴、多少同时联动轴，以及控制系统/插补能力如何？
4. **自动化和工艺集成**：是否具备自动换刀、托盘交换、上下料、复合工艺或单元/生产线集成？

联合国CPC 3.0第4421类与JMTBA产品目录提供产品类型证据；二者是不同目的的分类资料，不应强行合并成一个声称“全球唯一”的工程分类。〔SRC-000001；SRC-000004〕

## 2. 本项目分类树

数控机床/机床产品（项目工作范围）
- 金属切削机床
  - 车床与车削中心
  - 铣床
  - 加工中心：立式、卧式、五轴、龙门/双立柱
  - 钻床与镗床
  - 磨削与精整机床
  - 齿轮加工与齿轮精整机床
  - 刨/插/拉/锯及其他切削机床
- 特种/非传统加工机床
  - 电火花（成形EDM、线切割、穿孔）
  - 电化学/超声/电子束/等离子加工
  - 激光/水射流加工
- 金属成形机床
  - 冲压与压力机
  - 剪切
  - 折弯/弯曲
  - 锻压及其他成形
- 跨工艺/系统级类型
  - 车铣复合与多任务机床
  - 专用/组合机床
  - FMC/FMS（制造单元/系统层，不是单台机床类型）

## 3. 机型类别判别表

| 类别 | 主要判别依据 | 常见结构/变体 | 典型工件或工序 |
|---|---|---|---|
| 车床/车削中心 | 工件旋转为主要切削运动 | 卧式、立式、双主轴、多刀塔、动力刀具、走心式 | 轴、盘、套、回转体 |
| 铣床 | 旋转刀具与工件相对进给完成铣削 | 立式、卧式、床身、龙门 | 平面、型腔、曲面 |
| 加工中心 | 以数控多工序加工为主，通常配置自动换刀等集成能力 | 立式、卧式、五轴、龙门/双立柱 | 箱体、板类、模具、复杂多面零件 |
| 钻/镗床 | 以孔加工为主要任务 | 立式钻、摇臂钻、深孔钻、卧式镗、坐标镗 | 孔系、深孔、精密孔 |
| 磨削/精整 | 以砂轮/磨料和精整工具为主要加工工具 | 外圆、内圆、平面、无心、螺纹、工具、坐标磨 | 高精度尺寸/形状/表面 |
| 齿轮加工机床 | 以齿形生成及齿面精整为主 | 滚齿、插齿、磨齿、剃齿、珩齿、车齿 | 圆柱齿轮、锥齿轮、蜗轮蜗杆 |
| 特种加工机床 | 加工能量/介质为放电、电化学、激光、超声等 | 线切割、成形EDM、激光切割、水射流 | 难加工材料、细小特征、板材 |
| 金属成形机床 | 以塑性成形或材料分离为主要过程 | 冲床、液压机、剪板机、折弯机 | 板材、型材、锻件 |
| 多任务/车铣复合 | 多工艺在同一平台完成 | 车铣中心、双主轴、多刀塔、复合转台 | 多面、多工序回转体/复杂零件 |
| 专用/组合机床 | 结构和工艺围绕特定零件/节拍定制 | 单工位、多工位、模块化组合 | 大批量专用零件和固定工序 |

## 4. 横向维度（不可互相替代）

| 横向维度 | 典型值/类别 | 记录要求 |
|---|---|---|
| 主轴/工件布局 | 卧式、立式、倾斜、摆头、转台 | 说明观察方向、主轴方向和结构形式 |
| 轴配置 | 2/3/4/5轴及更多轴 | 记录可控轴总数、同时联动轴数、旋转轴位置和方向 |
| 自动化 | 手动装卸、自动换刀、托盘交换、机器人上下料、FMC/FMS | 明确哪些设备属于机床本体、外围设备或生产系统 |
| 工艺集成 | 单工艺、车铣复合、铣磨复合、激光/增材混合等 | 逐项记录机床具备的工艺及选件条件 |
| 控制平台 | CNC/PLC/驱动/反馈架构 | 记录厂商、产品系列、软件版本、现场总线和接口 |
| 工件范围 | 工件尺寸、质量、材料和批量 | 不凭机床类别推断加工范围，必须查具体规格书 |

**特别注意：**“5轴机床”不等于“5轴同时联动”；加工中心也不能仅凭名称推断其一定支持某种刀具接口、刀库容量或五轴功能。所有具体参数和功能必须回到型号/选项/版本文件。
