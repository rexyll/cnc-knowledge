# 数控机床维修工作流、工单与维修后复验

> **状态：** 通用维修管理框架（v0.1），不是任何品牌或型号的维修SOP；不提供现场拆装步骤、能量隔离操作步骤、参数设定值或通用验收限值。维修执行必须由具备相应资质/授权的人员，依据目标设备现行OEM服务手册、现场风险评估、适用法规和受控作业文件实施。
>
> **章节边界：** 本文聚焦“如何组织一次可追溯、可批准、可复验的维修”。症状分析、报警码解释和根因诊断知识归CH18；维护周期/耗材矩阵归CH17-T002；关键部件具体拆装和校准指导归CH17-T003。

## 1. 维修对象、目的与边界

数控机床维修（corrective maintenance / repair）是在设备发生故障、性能退化或不符合既定要求后，为恢复其规定功能而开展的受控活动。其交付不应仅是“换了一个部件”或“报警消失”，而应形成可追溯的闭环：

- 维修对象和设备配置可识别；
- 故障现象、工况和原始证据可复查；
- 危险源、人员资质和作业授权已确认；
- 维修依据、变更内容和替换件可追溯；
- 维修后验证覆盖本次变更影响的功能；
- 放行由有权限的责任人作出，遗留风险和后续观察条件已记录。

本文不替代OEM操作/维护/服务手册、设备专用能量控制程序、风险评估、企业维修制度、合同验收规范、功能安全验证文件或当地法规。

### 1.1 与相邻章节的职责分配

| 工作内容 | 主归属 | 本文处理方式 |
|---|---|---|
| 日常点检、保养、润滑、过滤、周期管理 | CH17-T002 | 只定义工单如何引用维护计划，不填写通用周期 |
| 部件拆卸、安装、配合、调整、校准的具体工艺 | CH17-T003 / CH04 / CH16 | 只要求引用OEM步骤、工具和复验条款，不复制未经授权的服务程序 |
| 报警码、症状到候选根因、诊断树、FMEA | CH18 | 工单关联诊断记录；不得凭单一症状直接断言根因 |
| 维修后几何精度、定位精度和性能测试 | CH14 | 选择适用测量方法和合同/制造商验收准则 |
| 标准法规与安全适用性 | CH15 | 记录适用版本、管辖范围及评估结论 |
| 设备实例、备件、图纸、BOM与文档版本 | CH16 / CH19 / CH20 | 用稳定ID、序列/批次和文档修订号建立追溯 |

## 2. 维修工作的分类

维修分类用于确定参与角色、证据要求和复验范围，不是故障根因结论。

| 维修域 | 典型对象 | 重点记录的接口 | 复验关注点（具体项目以OEM文件为准） |
|---|---|---|---|
| 机械传动与导向 | 导轨、滚珠丝杠、联轴器、轴承、支承、齿轮/皮带 | 配合关系、润滑、预紧、定位基准、紧固件和防护 | 运动状态、异常振动/温升、定位/几何性能及润滑状态 |
| 主轴与刀具系统 | 主轴单元、主轴驱动、刀柄夹持、刀库、换刀机构 | 主轴/刀具接口、夹持状态、冷却、润滑、速度反馈 | OEM规定的运行、温升、振动、跳动/精度和换刀功能检查 |
| 进给轴与伺服反馈 | 电机、驱动器、编码器/光栅、制动器、线缆 | 相位/极性、反馈方向、参数版本、机械负载和电缆屏蔽 | 轴向运动、反馈一致性、报警状态及适用的定位/重复定位测试 |
| 电气与控制 | 电源、接触器、保护器件、I/O、CNC/PLC模块 | 电气接口、端子/线号、接地、程序和配置版本 | 电气检查、I/O功能、报警记录、受控程序/参数恢复和功能回归 |
| 液压与气动 | 泵站、阀、管路、蓄能器、夹紧/松开回路 | 压力储能、介质、密封、夹紧/释放反馈 | OEM规定的压力/泄漏/动作和夹紧状态验证 |
| 润滑、冷却与排屑 | 集中润滑、冷却泵/过滤、热交换器、排屑机 | 流量/压力/温度监测、介质规格、污染和泄漏 | 供液状态、泄漏、报警、过滤/排屑功能以及规定的介质指标 |
| 防护与安全功能 | 防护门、联锁、急停、限位、光栅、安全回路 | 安全回路配置、诊断状态、复位权限和风险评估 | 按OEM安全验证程序和适用法规验证；未验证不得放行 |
| 几何与加工质量 | 基础、直线度、垂直度、回转轴、测头/刀具测量 | 测量基准、环境、测量设备校准状态、补偿版本 | 与本次维修影响相匹配的测量项目及首件/试切验证 |

同一工单可以覆盖多个维修域；应将每个更换件、参数变更和验证项目分别列出，避免用笼统的“整机调试正常”掩盖未验证的子系统。

## 3. 维修闭环流程

### 3.1 报修与设备状态固化

建立唯一工单ID，关联机床实物实例ID（MINST）、整机型号（MACHINE）、控制系统/软件版本、选件配置和生产工单。报修时记录首次发生时间、报警原文/代码、发生频度、运行模式、程序号/版本、刀具/工件/夹具、加工材料和工艺条件；同时保留操作者观察到的原始现象、CNC/PLC/驱动器日志时间范围、设备当前状态、临时隔离措施和相关工单。

保留原始证据，不应只保留转述后的“故障描述”。不得为复现故障而擅自解除防护、扩大运行范围或重复执行可能造成伤害/设备损坏的动作。

### 3.2 风险评估、停机和危险能量控制

维修计划应识别所有可能导致非预期启动、运动或能量释放的危险源，包括但不限于：

- 电源、驱动直流母线、电容及其他电气储能；
- 液压、气动、真空和蓄能器等压力能；
- 重力轴、配重、悬挂部件和可能下落的运动部件；
- 主轴、刀具、卡盘、转台和排屑机构的旋转/惯性；
- 弹簧、夹紧机构、制动器及机械预紧；
- 热表面、切削液、润滑剂和清洗介质等热/化学危害。

应依据具体设备的书面能量控制程序、现场风险评估和适用法规，由获授权人员实施隔离并验证其有效性。操作面板停止、急停、伺服禁能或软件互锁本身不能被默认视为完成能量隔离。本文不提供隔离点识别、断电顺序、放电时间、压力释放步骤或复能步骤；这些必须来自设备专用程序。

美国工作场所可在适用范围内参考 OSHA 29 CFR 1910.147。该规则覆盖可能因意外启动、意外通电或储能释放而造成伤害的设备维修/维护活动，并规定雇主能量控制计划、程序、培训和周期检查等要求；其适用范围和例外需按具体工作场景判断，不能替代其他国家/地区法规或设备专用程序。[SRC-000382](../data/sources/SRC-000382.json)

### 3.3 资料、人员和作业授权审查

制定维修工作包前，至少核对：

1. OEM服务手册与设备型号、序列范围、硬件选件、控制软件版本是否匹配；
2. 服务文件修订号、步骤引用、专用工具、耗材及替换件料号是否明确；
3. 作业人员是否获得该类电气、机械、液压/气动或安全功能工作的授权；
4. 外包服务商与现场设备责任方是否完成作业边界、能量控制和交接约定；
5. 参数备份、PLC/CNC程序、驱动器配置、补偿表和网络配置是否已有可验证的当前备份；
6. 复验计划、测量设备和判定准则是否在开工前确定。

Haas官方手册目录按产品族提供操作和服务资料，并包含润滑、排屑/冷却、刀库及主轴等子系统服务资料示例；实际执行必须选择目标型号与配置对应的现行修订，不能将一个产品族的步骤推广到其他型号或品牌。[SRC-000386](../data/sources/SRC-000386.json) 制造商资料对操作者可执行维护与专业服务的边界也可能不同，必须以具体设备手册为准。[SRC-000387](../data/sources/SRC-000387.json)

### 3.4 诊断、维修决策与工作包

诊断过程应形成独立记录，至少包含观察事实、测试方法、测量设备、原始数据、候选原因、排除证据、最终根因状态和置信程度。诊断结果应区分：

- **已证实根因：** 有直接测量、部件检验或可重复证据支持；
- **可能原因：** 仍有未排除的竞争假设；
- **未确定：** 当前证据不足，不得将推断写成确定结论；
- **多因/链式失效：** 记录触发因素、直接失效和系统级后果，避免只记录最后损坏的零件。

详细症状分析和诊断树转入 [CH18 故障诊断与可靠性](../18-fault-diagnosis-and-reliability/README.md)。维修决策可选择调整、修复、更换、返厂服务、限制使用或停机等待；必须记录技术依据、风险、备件身份和批准人。更换件需核对型号、修订、接口、额定能力和适用配置；外形或接插件相同不能证明电气、固件、精度或安全兼容。

### 3.5 执行与变更追溯

维修过程中按批准工作包记录每项操作的执行人、时间、引用的OEM章节、工具、耗材、拆下件/装入件身份，以及发现的偏差。尤其注意：

- 不得把未经验证的驱动参数、PLC程序、CNC参数或补偿文件写入设备；
- 参数恢复前核对设备型号/序列范围、软硬件版本和备份校验信息；
- 任何参数、固件、程序、网络或安全配置变化均应单独登记变更记录；
- 对拆下件保留必要的序列号、批次、失效现象和检验结果，以支持返修、质保和失效分析；
- 维修中发现与原工单无关的安全缺陷，应暂停相关作业并按企业流程升级。

### 3.6 维修后验证和放行

验证范围由“维修影响分析”确定：修复对象本身、与之相连的接口、受影响的安全功能、控制参数和加工质量均要考虑。使用本章资源中的 [维修后复验矩阵](../../resouces/17-operation-maintenance-and-repair/post-repair-verification-matrix.csv) 建立逐项计划，并记录实际方法、原始结果、判定来源和责任人。

可考虑的公开方法入口包括：

- ISO 17359:2018 为机器状态监测计划的建立提供通用指南，可用于规划趋势数据、监测对象和监测程序；该标准本身不提供某台机床的报警阈值、维护周期或故障结论。[SRC-000389](../data/sources/SRC-000389.json)
- ISO 230-2:2014（含 Amd 1:2016）规定数控机床单个线性/回转轴通过直接测量确定定位准确度和重复定位精度的方法，可在适用时用于周期核验、补偿或验收测试；它不等同于多轴同时运动测试，也不能自动提供所有维修的统一放行限值。[SRC-000390](../data/sources/SRC-000390.json)

标准方法是否适用，要结合维修对象、机床结构、合同要求、环境条件、测量设备不确定度和目标版本判断。测量结果应同时记录方法版本、测量方向/位置、环境、仪器校准状态和数据处理口径。复验未完成、关键结果超限或安全功能未验证时，不得以“试运行正常”替代正式放行。

### 3.7 设备恢复、交接与关闭

放行前应确认：工具/临时支撑和作业材料已按受控程序清点；防护和安全装置已按OEM规定恢复并验证；配置/参数变更已审核并备份；生产、维护和质量责任方收到状态交接；未解决偏差有明确限制、责任人和复查期限。

工单关闭至少包含维修结论、根因状态、替换件和耗材、参数/软件版本、复验报告链接、放行决定、批准人、恢复时间、遗留问题及后续观察触发条件。若设备被限制使用或仍处于待观察状态，应明确标记，不能在工单中写成“完全恢复”。

## 4. 角色与批准责任

| 角色 | 主要职责 | 不应代替的职责 |
|---|---|---|
| 操作人员/报修人 | 描述现象、提供工况、报警原文和设备状态；按现场指令停止使用并交接 | 不自行判断根因或执行未授权维修 |
| 维修计划员/设备负责人 | 建立工单、确认设备身份/手册版本、协调资源和风险评估 | 不以排产压力覆盖安全/质量放行条件 |
| 授权维修人员 | 按工作包实施维修、保留原始数据、记录偏差和替换件 | 不擅自旁路安全装置或改变未批准参数 |
| 诊断/技术支持人员 | 分析证据、提出根因假设和修复建议 | 不把可能原因表述为已证实事实 |
| 质量/计量人员 | 确定适用测量方法、测量设备和结果判定；独立复核关键指标 | 不用不适用标准替代合同/制造商判据 |
| 设备放行责任人 | 审查复验和遗留项，批准恢复生产或限制性放行 | 不在关键安全/性能验证缺失时签署完整放行 |
| OEM/外部服务商 | 对其授权范围内的产品、程序和服务给出技术支持 | 不替代现场雇主的法定安全责任和现场风险控制 |

角色可按组织规模合并，但作业执行、技术复核和最终放行的权限边界必须明确。

## 5. 工单数据模型与记录原则

维修工单模板采用“一个工单对应一次维修活动”的组织方式。推荐关联关系：

- 一个工单关联一个机床实物实例 MINST；若一次活动跨多台设备，应分别建立子工单；
- 工单可关联多个故障模式 FAULT、报警 ALARM、部件 PART、文档 DOC、来源 SRC 和测量/验证记录 MEAS；
- 每个替换件记录拆下件和装入件身份；有批次/序列号时记录批次/序列号，不得只记录通用名称；
- 配置变更、参数备份和复验报告均使用稳定文件/记录ID；敏感信息按权限管理；
- 时间戳使用带时区的 ISO 8601；数值记录单位、测量条件、仪器和来源；不适用项要写明理由。

工单模板见 [repair-work-order-template.csv](../../resouces/17-operation-maintenance-and-repair/repair-work-order-template.csv)。空白模板不是设备档案，也不包含任何厂商专属步骤或判定限值。每台设备的实际工单应保存在企业授权的维护系统或受控记录库中，避免将客户、人员和现场敏感数据直接提交到公开仓库。

## 6. 维修后复验矩阵的使用

复验矩阵是“覆盖提醒”，不是自动验收标准。每行均须填写适用性、实际测试方案、接受准则的来源、测量设备、执行人与复核人。未适用的项目要给出理由；与维修影响相关的项目不能无理由跳过。

建议至少覆盖：安全功能、电气/驱动、轴与反馈、主轴、ATC/夹持、压力系统、润滑/冷却、几何/定位、CNC/PLC参数、加工首件和文档配置。任何一个安全相关测试失败或未完成，都应阻止正常生产放行，直到按组织制度和适用法规解决。

## 7. 当前限制与下一步

1. 当前没有用户指定的机床制造商、型号、序列范围、CNC/PLC版本和选件；因此没有写入型号级维修步骤、维护周期、油液牌号、压力/扭矩/温度限值或备件替代关系。
2. 当前模板不包含真实维修工单、真实故障数据、客户现场记录或实测复验结果。
3. CH18 尚未建立诊断库；本文仅定义维修工单与诊断条目的接口，不预先填入报警代码和故障原因。
4. 下一步应先确定目标机型并取得对应受控OEM服务手册，再开展具体部件更换、维修后测量和备件兼容性研究。
