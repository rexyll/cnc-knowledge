# 主轴、伺服与滚珠丝杠专项更换工作包模板

**知识条目：** KNOW-000025  
**任务归属：** CH17-T003  
**状态：** 通用专项模板；不是品牌/型号维修SOP

本专题将通用部件更换工作包细化到三个高影响部件族：主轴单元、伺服电机/编码器、滚珠丝杠/支撑轴承。配套CSV模板分别定义专项检查点，适用于建立单次维修工作包时复制、裁剪和审批。它们不是按部件名称即可直接执行的拆装步骤，也不代表所有机床具有相同结构。

## 1. 使用原则与共同工作流

每个专项工作包必须唯一绑定设备实例、机床序列号、配置修订、CNC/PLC/驱动软件版本、部件BOM位置、旧件和新件完整身份、工单编号、OEM文件修订与现场风险评估。设备身份、文件适用性、替代兼容性、人员授权、危险能量控制、工具量具状态、拆前基线、安装记录、恢复/校准、维修后验证和放行，均由[部件更换工作包总体框架](component-replacement-work-package.md)统一控制。

专项CSV每一行是一个待审查检查点。字段包含原部件与替换件身份、组件子型、BOM位置及替代批准引用；工作阶段、检查域、问题和证据；OEM步骤来源、关键技术值来源和验收判据来源；责任专业、危险能量/停工点、适用性及执行状态；测量设备登记号、实际结果、偏差、复核人和时间。

使用时复制为具体工作包记录，并按设备配置裁剪不适用行，但必须留下不适用理由、审核人和依据。缺少适用性信息不等于N/A；缺少OEM程序或关键值来源时必须保持BLOCKED。表格默认TO_BE_ASSESSED / NOT_TESTED，任何PASS必须关联原始结果与可追溯判据。

## 2. 主轴单元专项更换工作包

适用子型可能包括主轴总成/主轴芯轴单元、主轴电机、主轴轴承相关总成、编码器/定向反馈器件、刀具夹持/拉刀机构及其驱动部件。实际设备可能把电机、轴承、反馈和夹持机构集成为不同结构；先通过BOM、序列号和OEM部件图确认工作边界，不得仅凭“主轴总成”名称推断内部结构。

拆前记录主轴单元完整产品/装配号、修订和序列信息；主轴电机及驱动配套；编码器、定向反馈和相关传感器；刀具接口/刀柄系统；润滑、冷却及热管理配置；主轴报警、运行小时/循环计数和历史维修记录。已有跳动、定位、振动、温升或噪声数据仅在测试条件可比、来源可靠时作为基线，不以主观描述代替测量记录。为采集基线而解除防护或执行未授权带危险运动操作不被允许。

替代兼容性必须核对整机适配范围和序列/选件约束、完整订货号和修订、主轴与电机/驱动组合、反馈与定向接口、刀具夹持系统、机械定位接口、润滑冷却要求、密封/污染要求以及安全功能。涉及转子/轴承组件时，OEM可能规定成套配对、平衡等级、特定装配或运输要求；只有适用OEM文件或正式工程批准才能确认，不能按外形、额定转速或接口相似自行认定替代。

主轴拆换可能关联旋转惯性、重物吊装、悬置/支撑、储能、刀具夹持、液压/气动执行件、电气驱动储能和高温介质。危险能量识别、支撑/吊装、隔离验证和恢复供能必须遵循目标机型OEM程序及现场适用制度，由有资质人员执行。本文不提供吊点、吊具选型值、支撑位置、拆卸顺序、主轴保持/释放方法或电气柜操作步骤。

安装基准、配合/定位、紧固和保持方法、润滑/冷却恢复、连接和参数/反馈配置，均须绑定OEM文件编号、修订及条款/图号。跳动、振动、热运行、转速/定向或刀具夹持试验，应由维修影响分析与OEM测试方案决定。没有统一的主轴更换验收数值，不能从通用模板推导试验顺序、运行条件、仪器和限值。

## 3. 伺服电机与编码器专项更换工作包

适用子型包括进给轴伺服电机、绝对/增量编码器、独立反馈单元、制动器和伺服驱动模块。此处模板以进给伺服轴为主；主轴电机的耦合关系应与主轴专项工作包交叉引用，不要把两个子系统的验收混为一体。

拆前记录轴名称/方向、驱动通道、CNC/PLC和驱动版本、原电机与反馈订货号/修订/序列信息、反馈类型与接口、制动器配置、联轴器/减速机构（如有）、电缆和连接器编号。按OEM诊断能力和安全条件保留报警、伺服诊断、跟随误差/负载趋势、参考点/零位、反馈读数、原参数和补偿备份。不同固件或设备实例的备份不能被视为可直接互换文件。

新电机必须有与指定驱动器、供电系统、反馈接口、制动器（如有）和机床软件配置相匹配的证据。审核电机/驱动配套表、连接器和线缆定义、反馈协议/分辨率、换相或参数要求、屏蔽接地、电缆路径和EMC要求。编码器更换与电机更换不是相同工作范围，需单独标明是否影响反馈安装基准、方向、参考点和绝对位置数据。

伺服驱动电路可能存在储能；轴可能有重力载荷、弹性载荷、制动器或外部机械耦合。能量隔离、储能验证、重力轴支撑和制动功能保护只能按现场程序和该机型OEM服务文件执行。不得提供通用直流母线放电等待时间、端子测量点、拆线顺序、制动器释放方式或参数修改方法；文件缺失时保持BLOCKED。

按OEM流程核验驱动/电机/反馈配套、软件与固件兼容、备份版本、轴方向、参考点/回零行为、限位与安全功能。是否需要重新校准反馈、恢复绝对位置、执行单轴定位/重复定位测试或重新建立补偿，应根据实际受影响范围决定。适用时可以把ISO 230-2作为单轴定位/重复定位方法入口（SRC-000390），但测试配置、执行程序和验收限值仍以OEM/合同规定为准。不得通过放宽跟随误差、屏蔽报警或旁路安全功能达到“通过”。

## 4. 滚珠丝杠与支撑轴承专项更换工作包

适用子型可能包括滚珠丝杠与螺母副、固定端/支撑端轴承组件、联轴器、锁紧和定位组件。OEM可能将丝杠、螺母、轴承和相关零件作为配套组件管理；没有明确替代文件前，不应把单件可采购等同于组合可互换。

拆前记录对应轴和安装位置，丝杠完整型号、长度/导程/精度等级等产品身份（字段以OEM资料定义为准）、螺母副配套身份、支撑轴承型号和布置、联轴器与电机接口、润滑系统和覆盖件配置。保留已有轴几何、直线度/平行关系、定位/重复定位、反向间隙或其他诊断数据、参考点和补偿备份，以及异常和负载/温度趋势。无法确认的几何基准不得从旧件外观估算。

核对完整BOM及OEM成套关系，包含丝杠与螺母配套、支撑轴承型号/布置、联接件、润滑方式、密封/刮屑结构、行程范围与覆盖件。安装基准、支撑定位、轴线关系、预紧/间隙、锁紧、热伸长/浮动端设计和润滑介质均可能影响精度与寿命，必须引用目标机型的装配图和受控工艺；不得从轴承/丝杠通用目录直接推导机床装配值。

丝杠和移动部件可能涉及重力轴、悬置部件、配重/制动系统、弹性储能、精密部件受损和污染风险。部件支撑、搬运、吊装、轴运动控制及现场隔离须由风险评估确定，并严格遵循OEM程序。本文不提供固定/浮动端拆装顺序、丝杠支撑方法、预紧量、锁紧扭矩、螺母安装/滚珠处理步骤或回零操作步骤。

需要记录OEM规定的基准/对中、轴承与螺母预紧、紧固/锁紧、联轴器接口、润滑恢复和覆盖件复装要求。复验可能包含适用的全行程运动、限位/参考点、定位/重复定位、几何关系、温度/振动趋势或补偿核验，具体范围依据更换影响分析确定。ISO 230-2仅作为单个NC轴定位/重复定位测试方法入口；本模板不提供测试参数或合格限值。

## 5. 三类专项模板的控制门

- **G0 设备身份与文件适用性：** 序列号、选件、改造、软件版本和OEM文件范围确认。
- **G1 安全与授权：** 任务风险评估、人员资格、作业许可及现场能源控制方案批准。
- **G2 旧/新件身份与兼容性：** 完整料号、修订、配套关系和OEM替代依据。
- **G3 拆前基线：** 配置备份、诊断和需要的测量数据归档。
- **G4 工具与程序：** 专用工装、吊装方案、量具状态及受控拆装程序齐备。
- **G5 安装与关键值：** 所有关键技术值均有OEM或批准工程来源；不得靠经验补齐。
- **G6 恢复与复验：** 参数/补偿、功能、安全、精度/状态测试按批准方案完成。
- **G7 放行与归档：** 偏差关闭、证据齐备，具有权限的人员签署放行。

任一控制门缺少关键证据时，按工作包规则保持BLOCKED。安全联锁和保护功能不得旁路；所有维修、测量和放行必须由适格人员在受控现场体系中执行。

## 7. 来源、验证状态与遗留事项

- SRC-000390：ISO 230-2:2014及2016修正案官方目录，仅作为NC单轴定位准确度/重复定位方法入口；具体测试方案和验收限值由OEM/合同确定。
- 当前没有指定目标机床、序列范围、选件和受控服务手册，因此三份专项表格是待映射的工作包模板，不含已确认型号步骤、替代关系或数值。
