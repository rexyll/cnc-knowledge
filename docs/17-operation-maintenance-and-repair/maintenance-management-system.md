# 数控机床计划维护体系与维护任务管理

> **状态：** 通用计划维护体系框架（v0.1），附制造商专属维护计划实例。本文不建立跨品牌通用维护周期，不规定油液牌号、加注量、压力、浓度、温度、扭矩、过滤精度或寿命限值。实际计划必须绑定机床型号、序列范围、选件、运行条件和现行OEM手册。
>
> **边界：** 本文处理维护策略、任务编排、触发机制、保养记录和耗材追溯。操作人员班前检查见 `operation-readiness-checklist.csv`；故障维修工单与维修后复验见 `repair-workflow-and-records.md`；具体部件拆装、调整和校准留待CH17-T003。

## 1. 计划维护的目的与对象

计划维护（planned maintenance）是按预先定义的时间、运行量、循环计数、状态或事件安排的维护活动。它不等于“定期换件”：每项维护任务必须有明确对象、适用配置、触发依据、作业权限、方法、判据和记录要求。

机床维护计划需要覆盖整机及已安装选件，而不是只按机床名称套用一张通用表。建议至少建立以下设备层级：

- **整机实例：** MINST、整机型号MACHINE、序列/资产标识、投产日期、安装地点和配置快照。
- **功能子系统：** 主轴、进给轴、刀库/换刀、工件夹持、润滑、冷却、液压、气动、排屑、防护、电气控制和测量系统。
- **可维护对象：** 部件PART、耗材料号、滤芯/密封/皮带/润滑点、测点和计数器。
- **文件基线：** OEM操作/维护/服务手册编号、修订、适用序列范围、选件和补充服务通告。

未安装的选件、未配置的回路或不存在的部件应标记为不适用并留理由，不能为了填满表格而创建虚构维护项目。

## 2. 维护策略分类

| 策略 | 触发机制 | 适用情形 | 计划依据与限制 |
|---|---|---|---|
| 操作者日常照护 | 班前/班后、操作前后 | 外观、状态指示、可见液位/泄漏、工作区清理 | 只执行OEM明确授权给操作者的检查和保养；与班前检查表衔接 |
| 时间周期预防维护 | 日历时间或运行时间到期 | 润滑、过滤器、规定检查/更换项目 | 周期必须来自适用OEM文件或适用法规；明确计时起点、允差和停机窗口 |
| 使用量/循环维护 | 主轴小时、轴运行小时、换刀次数、加工循环等计数器 | 与磨损、动作次数或使用量相关的项目 | 只有在OEM定义计数器与阈值后才能配置；不能自创“累计小时”代替指定计数 |
| 状态维护 | 实测状态、趋势或诊断结果达到批准条件 | 振动、温度、润滑状态、污染、泄漏、磨损和精度趋势 | 测点、采样、基线、阈值和告警逻辑须有OEM或经批准的现场依据 |
| 事件触发维护 | 碰撞、过载、异常停机、介质污染、部件更换或长期停机等事件 | 需要额外检查、复验或恢复的场景 | 事件触发条件、检查范围和恢复授权必须由OEM/企业程序定义 |
| 纠正性维修/检修 | 故障、缺陷或状态超限 | 故障修复、部件更换、参数恢复、大修 | 通过维修工单管理；不应伪装成正常计划保养任务 |

同一任务可能同时受到多个触发条件约束。只有当OEM文件明确规定组合逻辑时，才能按“先到期者触发”、主/从计数器或条件覆盖规则计算；否则应把各触发条件分别登记并由设备责任人确认，避免擅自改变制造商策略。

## 3. 维护周期与触发依据的配置规则

### 3.1 证据优先级

每条维护任务应记录实际采用的依据及适用边界：

1. **目标型号现行OEM维护/服务手册：** 首要依据；核对型号、序列范围、软件/硬件版本、选件和文件修订。
2. **OEM服务通告/技术公告：** 核对发布日期、适用序列范围、生效条件，以及是否替代旧版任务。
3. **适用法规或合同要求：** 记录司法辖区、设备类型、工作场景及约束对象；不得把某地区法规套用于其他地区。
4. **现场状态监测方案：** 记录批准人、测点、方法、基线、阈值来源和复核周期；不可用单个标准编号推导通用报警值。
5. **经批准的工程经验：** 明确标记为现场策略而非OEM要求，记录样本、工况、批准和复审日期；不得冒充原厂周期。

如果不同文件冲突，先记录冲突版本、适用范围和差异，再由OEM或设备技术责任人确认。不得自行选取较宽松的周期。

### 3.2 触发数据

维护任务矩阵至少记录：

- 触发类型：CALENDAR（日历）、RUNTIME（运行时间）、CYCLE（循环/次数）、CONDITION（状态）、EVENT（事件）或OEM定义的组合类型；
- 原始周期/阈值、单位、计数器名称、计数起点、复位/更换规则；
- 适用机型、选件、环境、材料、班次、负载及加工介质条件；
- OEM文件编号、修订、章节/表号、来源ID及核验日期；
- 任务负责人、执行资格、危险源和前置条件；
- 完成日期、完成时计数器值、实测值、结果、异常工单和下次到期依据。

当OEM要求按条件缩短周期时，应记录触发条件及依据，不要把缩短后的现场规则改写为制造商原始要求。停机封存、低负载、重负载或特殊材料的处理也必须引用OEM或现场批准方案。

### 3.3 到期与延期管理

维护计划系统可以显示NOT_CONFIGURED、PLANNED、DUE、OVERDUE、BLOCKED、COMPLETED、NOT_APPLICABLE等状态，但状态本身不是允许超期运行的授权。

- **DUE/OVERDUE：** 按原始计划安排维护，不自行延长周期。
- **BLOCKED：** 缺少手册、备件、授权、停机窗口或安全前置条件；必须记录责任人和升级路径。
- **延期：** 记录原因、风险评估、批准人、临时控制措施和新的复审时间；不得覆盖原到期时间或伪造按期完成。
- **NOT_APPLICABLE：** 说明对应选件未安装、部件不存在或OEM明确不适用的证据。
- **COMPLETED：** 仅在任务按规定执行且记录完成后使用；异常结果应转入维修工单/故障记录，而不是简单标记完成。

## 4. 按子系统建立维护任务

下表是维护任务分类入口，不是通用周期表。各行需要绑定具体设备的OEM任务、检查方法和判据后才能激活。

| 子系统 | 维护对象/任务类型 | 记录重点 | 关键边界 |
|---|---|---|---|
| 防护与门机构 | 窗体、门、护罩、导轨罩和联锁相关检查 | 外观状态、缺陷、OEM指定功能检查 | 安全功能测试只按OEM/适用法规规定的方法执行，不旁路联锁 |
| 进给轴/润滑 | 油箱液位、管路、分配器、润滑功能和润滑点 | 油品型号、料号、计量/报警状态、泄漏、执行记录 | 润滑剂、加注量、频次和测试方法均需型号级依据 |
| 导轨/丝杠 | 润滑点、护罩、可见污染/异常 | 部件配置、润滑要求、异常趋势和维护工单 | 不以“通用导轨油”替代OEM规格；拆装和预紧另见T003 |
| 主轴 | 润滑、冷却、过滤、运行状态 | 润滑系统状态、温升/振动趋势、报警和OEM试验记录 | 不设通用转速、温度、振动或跳动限值 |
| 变速箱/传动 | 油位、油品状态、换油/过滤项目 | 具体型号、油品规格、容量、替换滤芯及废液记录 | 换油周期与油品型号按OEM及配置核对 |
| 刀库/ATC | 刀臂、刀位、夹持、换刀机构和气动接口 | 动作计数、异常记录、部件版本和服务通告 | 不用强制动作或旁路保护进行检查 |
| 工件夹持 | 卡盘/夹头/尾座/夹具 | 润滑点、磨损、夹持状态、OEM检验记录 | 不推断夹紧压力、夹持力和润滑剂 |
| 冷却与过滤 | 冷却液液位/浓度、过滤、油水分离、泵与管路 | 介质规格、浓度测量方法、过滤器料号、批次与处置 | 浓度、pH、流量、温度和换液条件不得套用其他工艺 |
| 液压 | 油位、过滤、泄漏、介质更换 | 液压单元型号、油液规格、滤芯型号、污染/检测记录 | 储能释放和压力回路作业仅由授权人员按设备程序执行 |
| 气动 | 调压/过滤/润滑单元、软管和泄漏 | 介质/过滤状态、OEM压力判据、管路更换记录 | 不提供统一压力或拆管步骤 |
| 电气与控制 | 柜体冷却、通风滤网、风扇、备份和版本基线 | 柜体配置、风道/滤芯状态、版本校验、变更记录 | 柜内作业按电气安全/能量控制程序由授权人员执行 |
| 测量/探测 | 测头、刀具测量、对刀仪和探针校准 | 校准证书、方法、测量设备、补偿版本 | 校准周期和接受限值需OEM、计量规程或合同依据 |
| 排屑与辅助设备 | 排屑器、油雾/油水分离、接料器、送料器等 | 选件身份、动作/运行计数、耗材和接口状态 | 仅对实际安装的选件建立任务 |

## 5. 制造商维护计划实例：Haas车床

Haas官方交互式车床服务手册的维护页RD0035，修订版A（2026年4月），给出产品族维护计划实例。以下仅摘录少量用于说明“同一设备的不同子系统可能有不同周期”，不能直接套用到非Haas机床，也不能在未核对机型、序列范围、选件和液压单元类型时用于Haas现场执行。[SRC-000388](../data/sources/SRC-000388.json)

| 子系统 | 维护项目（摘要） | RD0035列示间隔 | 使用边界 |
|---|---|---|---|
| 防护罩 | 检查观察窗损坏 | 每日 | 仅对应手册适用的Haas车床 |
| 防护罩 | 检查门联锁运行 | 每日 | 具体功能测试方法按OEM安全程序 |
| 轴润滑 | 检查储油罐液位 | 每月 | 润滑油规格与补充条件按具体设备文件 |
| 轴润滑 | 检查软管开裂；执行轴润滑测试 | 每六个月 | 不在本文复制测试步骤 |
| 电气柜 | 清洁矢量驱动通风口/过滤器 | 每月 | 涉及柜内作业时须符合OEM授权和隔离规定 |
| 变速箱 | 检查油位；换油 | 每月检查；每年更换 | 油品、容量和步骤依具体配置 |
| 冷却液 | 检查液位、浓度 | 每周 | 依OEM介质和测量要求，不能推定其他冷却液标准 |
| 主轴润滑 | 检查润滑油箱液位；执行润滑测试 | 每月检查；每六个月测试 | 仅对应适用的Haas产品资料 |
| 液压 | 更换液压油 | 每两年或按状态需要 | 具体液压单元和工况须匹配 |
| 探针系统 | 检查探针校准 | 每六个月 | 测量判据、设备和校准方法按OEM |

原厂页面同时列出其他选件和子系统任务；本表只选取代表项目，不视为完整维护清单。需要执行前，应直接打开当前交互式手册并核实序列范围、选件、具体液压单元/附件版本和修订。[SRC-000388](../data/sources/SRC-000388.json)

## 6. 状态维护与趋势记录

状态维护不应仅设置“振动高/温度高”这样的主观告警。每个监测项目至少要定义：

1. 监测对象、测点位置、传感器/仪器、采样与数据处理方法；
2. 设备运行状态、速度/负载/环境和测量重复性；
3. 初始基线、正常波动、数据质量检查和趋势窗口；
4. 告警阈值、阈值来源、批准人、触发后的复测/升级动作；
5. 传感器失效、数据缺失、工况改变和测点迁移的处理。

ISO 17359:2018是机器状态监测与诊断的一般指南，可作为规划状态监测程序的标准入口；它不提供特定CNC机床的通用振动/温度限值，也不替代OEM手册和现场风险分析。[SRC-000389](../data/sources/SRC-000389.json)

趋势数据应与维护任务、维修工单及部件身份关联。如果维护前后测点、传感器、转速或负载条件不同，应先说明可比性限制，不能仅用两次读数之差断言维修有效或部件退化。

## 7. 保养任务执行与记录卡

每次维护都应形成独立记录，可使用 [维护保养卡模板](../../resouces/17-operation-maintenance-and-repair/maintenance-card-template.csv)。建议流程：

1. 核对任务到期状态、机床实例/配置、OEM手册版本及任务适用范围。
2. 核对人员授权、风险评估、需要的停机/隔离和作业前置条件。
3. 核对工具、测量设备校准状态、耗材规格/料号/批次及废弃物处理要求。
4. 按受控OEM程序执行；记录实测值、单位、检查方法和偏差，不只勾选“完成”。
5. 复核异常、替换件、参数变化和后续维修需求；需要纠正性维修时创建维修工单。
6. 记录完成时计数器值、下次触发依据、执行人、复核人和证据引用。

维护卡中的PASS只表示该记录项满足已明确引用的判据，不代表整机安全或加工性能已获认证。

## 8. 润滑剂、冷却液、滤芯与耗材管理

使用 [维护耗材登记模板](../../resouces/17-operation-maintenance-and-repair/maintenance-consumables-register-template.csv) 建立设备/子系统与耗材之间的可追溯关系。至少记录：

- OEM料号、规格/标准、产品名称、等级/粘度/基础油类型（适用时）；
- 适用机型、子系统、选件、接口材料和相容性；
- 指定用量、混用/替代禁令、过滤器精度等——仅在OEM文件明确给出时填写；
- 供应商与采购批次、批号、有效期、入库/开封/安装/更换日期；
- SDS/安全资料引用、仓储条件、泄漏处置和废液/废滤芯处理要求；
- 替代品审批记录、批准人和兼容性证据。

替代品不能仅凭粘度相近、品牌相同或供应商口头承诺判定兼容。未找到原厂规格、材料兼容性或批准文件时，状态保持OEM_SPEC_REQUIRED / BLOCKED，不填写推测品号和替代关系。

## 10. 当前缺口与下一步

- 当前没有指定目标机床型号、序列范围、控制系统版本、选件及运行工况，因此尚未激活任何通用矩阵任务，也没有将模板中的周期/阈值填成可执行计划。
- 已有Haas车床RD0035实例用于展示“制造商任务和周期具有产品族/配置特异性”；不是用户目标机型的维护计划。
- 下一步应选定目标机床系列，取得现行操作/维护/服务手册并建立配置清单；将任务矩阵逐行映射到OEM条款、到期计算、耗材料号和复验方法。
- 涉及危险能量、柜内作业、压力回路、安全功能和精度恢复的工作必须由获授权人员依据具体设备程序实施。
