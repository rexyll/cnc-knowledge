# 数控机床刀库/换刀机构、卡盘夹持与液压气动单元专项更换工作包

**知识条目：** KNOW-000026  
**版本：** 0.1  
**状态：** 模型无关专项工作包模板；待目标机型和OEM文件映射

## 1. 目的与适用边界

本文将CH17-T003通用更换工作包和九类部件影响矩阵细化为三组部件族：自动换刀系统（刀库、刀套、机械手、凸轮/链传动、刀塔及适用的动力刀具）；卡盘与工件夹持系统（卡盘、卡爪/软爪/筒夹、适配盘、拉杆/拉管、夹紧执行缸和旋转接头）；液压/气动动力单元（泵/电机、阀组、执行器、蓄能器、过滤、管路、传感器和保护元件）。

以下文件是**审查问题与记录字段模板**，不是通用拆装SOP、操作授权或验收标准。并非每项都适用于所有设备。使用前必须确认机床型号、序列范围、选件、主轴/刀库/夹持配置、CNC/PLC版本及受控OEM服务文件；不适用项目需留下依据。
