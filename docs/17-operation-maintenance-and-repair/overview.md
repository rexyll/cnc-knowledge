# 机床操作、维护与维修总览（CH17）

> **状态：** 第一版通用知识框架，不是任何具体机床的操作规程、维护周期表或维修作业指导书。实际工作须以目标机床制造商针对型号、配置和软件版本发布的现行手册、现场风险评估及适用法规为准。
>
> **范围：** 数控铣床/加工中心、数控车床/车削中心，以及进给轴、主轴、刀库/换刀机构、夹具、润滑、冷却、液压、气动、排屑和电气控制等子系统。

## 1. 工作类型与责任边界

| 类别 | 目的与典型内容 | 执行边界 |
|---|---|---|
| 操作（Operation） | 开机准备、程序/刀具/工件核对、试运行、自动加工、正常停机 | 经设备方培训并获授权的操作人员；遵循对应机型手册 |
| 操作者日常维护（Operator care） | 外观检查、清洁、查看状态/报警/液位、手册允许的简单保养 | 仅限手册明确允许操作者执行的项目 |
| 计划/状态维护（Preventive / Condition-based） | 周期检查、趋势记录、润滑/过滤系统检查、校准和预防性更换 | 维护计划指定的具备相应能力人员 |
| 故障维修/服务（Corrective maintenance / Service） | 故障诊断、部件更换、参数恢复、功能/精度复验 | 受训、授权的维修人员；涉及危险能量时执行适用的能量控制程序 |

不同制造商对操作、维护和服务的分界可能不同。Haas 铣床安全说明可作为产品族示例：其资料把操作、维护与服务区分，并将专业维修与操作者有限维护区别对待；该边界不得直接套用到其他品牌或型号。[SRC-000380](../data/sources/SRC-000380.json)

## 2. 按机床类型组织资料

- **铣床/加工中心：** 识别主轴、进给轴、刀库/自动换刀、工作台/交换工作台、冷却液、排屑、润滑、液压/气动和防护装置。ISO 16090-1:2022 的公开目录范围覆盖铣床、加工中心和转移机床；第三版工作草案仍在制定，不能当作已发布标准。[SRC-000383](../data/sources/SRC-000383.json) [SRC-000384](../data/sources/SRC-000384.json)
- **车床/车削中心：** 识别主轴/卡盘或夹头、刀塔、尾座/副主轴（如配置）、排屑、冷却和防护装置。ISO 23125:2015 的公开目录针对车床和车削中心；该版仍为已发布版本但处于修订流程，实际使用前须核对目标市场和合同要求。[SRC-000385](../data/sources/SRC-000385.json)
- **复合机床及特殊配置：** 逐项登记选件、自动化接口、工件/托盘交换、上下料接口、特殊夹紧回路和外围设备。不得仅凭“加工中心”名称推断设备实际配置。

ISO目录用于确认标准名称、版本、范围和状态，不等于标准全文或设备符合性结论。标准全文受版权约束，本仓库仅登记元数据和官方入口。

## 3. 设备生命周期工作流

### 3.1 开机前准备

1. **确认对象：** 核对设备型号/序列标识、控制系统版本、选件和现行操作手册；确认维修工单、停机挂牌或未关闭异常不会与启动操作冲突。
2. **确认现场：** 检查工作区域、通道、照明、地面和设备周边，避免工件、工具或切屑妨碍人员撤离或设备运动。
3. **观察防护状态：** 检查护罩、门窗、防护屏和可见安全装置是否完整；发现损坏、缺失、异常或被旁路迹象时，不得启动或继续生产，应按现场程序报告。
4. **核对设备状态：** 查看CNC报警及润滑、冷却、液压、气动等状态指示，只对照目标机型手册中的限值和检查方法。
5. **核对工装工件：** 确认夹具、工件、刀柄、刀具及支承/防松装置符合工艺文件，并检查运动包络是否存在干涉风险。
6. **核对程序与补偿：** 确认程序文件版本、坐标系、刀具表、长度/半径补偿和工艺参数与工单一致；未知或冲突项应先停止并澄清。
7. **按手册完成准备运行：** 回参考点、主轴/轴预热、刀库检查、空运行或单段验证等动作，必须按该型号制造商规程和现场风险控制执行；不假设统一速度、倍率或时间。

本框架不提供门锁/急停测试、回零或预热的具体操作步骤。功能测试必须遵循厂家规定的测试条件、周期和授权要求。

### 3.2 加工期间监视

监视控制系统报警、主轴/进给异常声响与振动、温升、泄漏、切屑排出、冷却/润滑状态和加工质量变化。出现不明报警、碰撞迹象、异常噪声、泄漏或防护失效时，按机型规定的安全停机/异常处置程序处理；不得屏蔽报警、短接联锁或提高保护阈值继续生产。

### 3.3 正常停机与班后工作

正常停机、刀具/工件卸除、工作区清理和切屑处理均应遵循目标机型手册。接近危险区域或处理排屑/清洁任务前，先判断是否属于维护/服务作业以及是否需要隔离危险能量；控制面板显示“停止”或按下急停，不等于完成能量隔离。

### 3.4 维护与维修工作流

1. 建立任务：关联设备实例、部件/子系统、故障现象或维护计划、工单编号和目标。
2. 核对依据：确认制造商手册版本、适用配置、作业人员授权、工装耗材及复验要求。
3. 评估风险：识别电气储能、气动/液压压力、重力轴/配重、主轴旋转、弹簧/夹紧机构、热表面和冷却液等危险源。
4. 控制能量：在适用法规和现场程序要求下，执行书面能量控制/上锁挂牌（LOTO）程序，由授权人员实施并验证隔离有效。美国 OSHA 29 CFR 1910.147 是其适用范围内的危险能量控制法规示例，不是其他国家或地区的通用法律替代品。[SRC-000382](../data/sources/SRC-000382.json)
5. 执行作业：使用适用机型的制造商维修程序和规定工具；超出人员授权、资料不全或发现未预期危险能量时，应停止并升级处理。
6. 复验与恢复：按制造商规定检查装配、防护、安全功能、参数/补偿、空运行和必要精度项目；确认人员和工具退出危险区域，再按现场能量控制程序完成恢复和交接。
7. 关闭记录：记录故障原因的证据等级、替换件身份、软件/参数变更、测量值、复验结果、未解决事项和下次检查触发条件。

**安全底线：** 不旁路急停、门锁联锁、光栅、限位或其他安全保护；不把急停/伺服禁能等同于电气隔离；不向未经授权人员提供带电柜内维修、高压直流母线处理、压力回路拆卸、配重/重力轴拆卸等危险操作步骤。相关工作须由受训且获授权的专业人员依据具体设备手册和现场能量控制程序执行。

## 4. 维护任务的数据结构

维护任务至少应关联以下信息：

- **对象：** 机床实例ID、制造商、型号、序列标识、控制系统/软件版本、选件、子系统、部件号/图号。
- **任务：** 任务ID、任务名称、维护类型（操作者日常、预防性、状态维护、纠正性、检修/大修）、触发条件、计划周期、运行小时/循环数依据。
- **授权与安全：** 责任角色、培训/授权条件、风险评估编号、能量控制/LOTO程序编号、所需防护与工具。
- **执行：** 手册编号/版本/章节、步骤来源、耗材/润滑剂/过滤件原厂规格和料号、检查方法、测量设备及校准状态。
- **结果：** 作业前/后状态、测量值与单位、判定标准来源、报警/故障码、替换件批次/序列号、复验项目、执行人/复核人、完成时间和下次触发条件。

### 4.1 维护周期与限值来源

维护周期优先由目标型号及选件对应的制造商维护手册决定，并记录其使用日历时间、运行小时、主轴小时、加工循环数还是状态触发。环境、负载、加工材料、冷却液和选件可能改变维护要求，必须检查手册适用条件。

Haas 交互式车床服务手册提供其车床产品族的维护计划并标明修订信息；其周期只能用于适用的Haas车床及配置，不能推广为所有CNC车床的统一周期。[SRC-000388](../data/sources/SRC-000388.json) Haas官方手册索引也按产品族提供操作/服务手册入口，应选择具体型号和文档修订。[SRC-000386](../data/sources/SRC-000386.json)

若无法取得具体机型的现行维护计划，周期、润滑剂型号、油脂等级、冷却液浓度、过滤精度、压力、扭矩和更换限值均记录为 UNKNOWN / TO_BE_VERIFIED，不用其他品牌手册或网络经验填补。

## 5. 标准和法规的适用方式

- **美国工作场所危险能量控制：** OSHA 29 CFR 1910.147 对其适用范围内的危险能量控制计划、程序、培训和周期性检查提出要求。须先判定雇主、设备、作业类型和管辖范围是否属于该规则；其他司法辖区应查验当地法规。[SRC-000382](../data/sources/SRC-000382.json)
- **铣床/加工中心安全：** ISO 16090-1:2022为已发布第二版，官方目录显示正在修订；ISO/WD 16090-1第三版仍处工作草案阶段，不能将草案等同已发布标准或直接作为合同验收依据。[SRC-000383](../data/sources/SRC-000383.json) [SRC-000384](../data/sources/SRC-000384.json)
- **车床/车削中心安全：** ISO 23125:2015第二版（含2016修正版本）为已发布版本，官方目录显示其处于修订状态。应用前应核对采购合同、目标市场和最新目录状态。[SRC-000385](../data/sources/SRC-000385.json)

本节只给出检索入口和范围提示，不复制标准受版权保护正文，也不声称某台机床已经符合标准。

## 6. 检查记录模板

resouces/17-operation-maintenance-and-repair/operation-readiness-checklist.csv 是本章原创空白检查记录模板，定义检查项、适用条件、责任角色、依据来源和结果字段；未填写型号、周期、参数或合格限值。使用时应为每台设备建立记录副本，并把实测结果关联到目标机型手册具体条款。

建议结果状态：NOT_ASSESSED（未检查）、PASS（按已记录来源符合）、FAIL（不符合，应停止相关操作并按现场流程升级）、NOT_APPLICABLE（不适用并说明理由）、BLOCKED（缺少手册、授权、隔离条件或其他前置条件）。PASS仅表示当前检查项满足记录的依据，不等于整机安全认证。

## 7. 当前缺口与后续工作

1. 获取至少一个目标机床型号及现行操作/维护/服务手册，建立型号、配置、版本和选件清单。
2. 把通用检查项映射到该机型实际HMI提示、厂商条款、周期和合格限值。
3. 建立维护任务矩阵、耗材/备件记录和保养历史模板，并与CH04零部件、CH16装配安装、CH18故障诊断及CH19厂商关系关联。
4. 对维修作业按风险分级；只整理有合法来源且适合授权人员执行的程序。涉及危险能量、精度恢复或安全功能验证的内容必须由制造商和具备资质的专业人员确认。
