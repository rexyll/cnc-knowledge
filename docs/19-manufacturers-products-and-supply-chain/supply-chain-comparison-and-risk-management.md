# 数控机床供应链比较、替代验证与风险管理

> 知识ID：KNOW-000011  
> 主章节：CH19  
> 版本：1.0  
> 核验日期：2026-11-22  
> 适用范围：数控机床整机及关键机械、电气、测量、控制和工艺部件的工程选型、替代评估与采购风险审查。  
> 方法属性：工程比较框架与采购核验流程，不构成供应商排名、价格行情或具体产品兼容性认证。

## 1. 目的与基本原则

供应链比较不能简化为品牌、目录参数或采购报价的横向排列。一个可执行的比较至少要回答：比较对象是否承担相同功能并处于相同系统层级；比较的是哪个完整订货型号、硬件/软件版本、选件和地区目录；机械、电气、通信、控制软件、工艺和安全接口是否逐项匹配；证据来自原厂文件、第三方测试、现场验证还是尚未取得；替代后是否需要重新设计、调试、标定、风险评估或验收；产品生命周期、备件、维修和当地服务是否有可追溯证据。

**核心规则：同品牌不等于兼容；同系列不等于可互换；尺寸相近不等于安装等效；原厂推荐替代不等于整机系统已验证。**

必须区分四种结论：

- 目录相似性：用途或分类相近，只能作为候选线索。
- 原厂替代声明：原厂明确列出替代型号及其适用范围。
- 接口兼容证据：指定型号/版本的接口、参数和约束已被文件或测试覆盖。
- 项目替代批准：指定机床配置和工况完成设计审查、风险评估及必要验证，并由责任方批准。

## 2. 比较对象与数据基线

### 2.1 先统一比较层级

不得将不同层级对象放入同一评分表。例如轴承与完整主轴单元、裸导轨与包含滑块/密封/润滑附件的组件、工件测头与刀具测量装置、刀片与完整刀具系统、零点快换模块与托盘/工作台接口均不是天然等价的比较对象。

先定义功能基线：功能、安装位置、载荷/工况、系统边界、必要接口、关键性能指标和失效后果。功能边界不一致时应拆分比较，不得用主观权重强行合并。

### 2.2 必须记录的比较主键

| 字段 | 记录要求 |
|---|---|
| 设备/机床对象 | 整机型号、配置、安装位置；序列号等敏感信息不得公开 |
| 现用件 | 原厂、完整订货代码、硬件/结构版本、软件/固件版本、选件 |
| 候选件 | 原厂、完整订货代码、硬件/结构版本、软件/固件版本、选件 |
| 适用地区 | 采购/安装/售后地区、原厂区域目录和当地法人/授权渠道 |
| 工况 | 载荷谱、速度、温度、润滑、污染、占空比、材料/工艺等条件 |
| 文件基线 | 图纸、规格书、手册、兼容清单、公告编号、修订版和发布日期 |
| 核验日期 | 每项结论最近核验日期；不同地区/版本不得共用未经确认的状态 |
| 责任方 | 设计、控制、电气、工艺、安全、采购和供应商确认岗位 |

缺少完整型号、版本或机床配置时，记录为 N/V（Not Verified，未验证），不得通过系列名称推断。

## 3. 兼容性证据等级

兼容性必须分域评价，不能用单一“兼容/不兼容”覆盖全部接口。以下C0～C4是本知识库内部方法，不是行业标准或厂商认证等级。

| 等级 | 名称 | 证据要求 | 可作出的结论 |
|---|---|---|---|
| C0 | 未知 / N/V | 型号、版本或接口资料不足 | 不作兼容判断，不打分 |
| C1 | 目录线索 | 用途/系列相近，尚无接口级证据 | 仅可进入候选清单 |
| C2 | 文件对照 | 指定型号的原厂图纸/规格/接口文件逐项对照，差异已列明 | 仅判断文件层面的匹配项与差异 |
| C3 | 台架/离线验证 | 明确边界条件下完成接口、电气、软件或功能测试 | 仅在测试覆盖的配置和条件内成立 |
| C4 | 目标机床验证与批准 | 目标机床完成必要装配、调试、标定、功能/安全验证及验收 | 仅对已验证机床配置、版本和工况有效 |

每个候选件分别记录机械、电气、通信、软件、工艺和安全六个域的证据等级。可使用字段：mechanical_compatibility_level、electrical_compatibility_level、communication_compatibility_level、software_compatibility_level、process_compatibility_level、safety_compatibility_level。不适用的域应说明原因，而不是留空。安全相关接口必须独立评审。

### 3.1 机械接口核验

检查外形尺寸、安装孔系、基准面、定位销/止口、配合公差、安装方向；载荷方向、载荷谱、力矩、刚度、预压、夹紧力及允许变形；运动范围、干涉、行程、极限位置、热伸长和维护空间；润滑方式、润滑剂、密封、污染和冷却条件；连接件、紧固件等级、安装工艺和预紧要求；关键尺寸链、精度恢复、现场测量方法和验收限值。

仅有外形图或公称尺寸相同，最多形成待验证候选，不能直接认定机械兼容。

### 3.2 电气与通信接口核验

检查供电电压/相数/频率、功耗、接地、保护和绝缘；输入输出类型、电平、极性、源/漏型、负载能力和隔离；连接器、针脚定义、线缆、屏蔽和布线；编码器/测量信号制式、分辨率、方向、供电和时序；总线协议、设备描述文件、通信周期、同步机制、拓扑和固件版本；EMC条件、接地策略、故障安全状态和断线/掉电行为。

连接器外形相同、协议名称相同或厂商均支持某总线，不足以证明电气/通信互操作。

### 3.3 软件、控制器与工艺接口核验

检查CNC/PLC型号、软件版本、选件、参数和可用功能；驱动器固件、设备描述文件、参数映射、控制模式和诊断语义；宏程序、循环、变量、报警处理、测量程序和后处理；插补/同步、补偿、标定、坐标变换、刀具管理和数据格式；工件材料、刀具、切削参数、冷却、排屑、夹持及质量验证；安全PLC、联锁、监控信号和整机安全验证的变更影响。

厂商声明“支持某品牌CNC”时，仍需核对具体控制器家族、软件版本、选件、宏程序包和安装条件。

## 5. 产品生命周期与停产风险

### 5.1 生命周期状态字段

按具体型号、版本和地区分别维护：

- active_confirmed：原厂当前资料或书面确认仍在销售/接受订单；
- limited_supply：原厂明确提示供应受限或仅剩库存；
- discontinuation_announced：已发布停产公告，但尚未到最后订货日期；
- last_order_passed：最后订货日期已过；
- support_end_announced：已公布支持/维修结束日期；
- support_ended_confirmed：原厂明确确认支持结束；
- unknown：没有足够证据判断。

不得把网页仍可访问、目录仍可下载或经销商仍有商品页面当作仍在售证据。停产公告中的替代型号也不代表全部配置一一对应。

### 5.2 生命周期风险核验项

核验原厂产品状态、公告编号、发布日期和适用地区；最后订货/交付日期及维修/备件支持截止日期；现有库存、备件消耗和关键易损件可获得性；维修能力、返修政策、校准能力、软件/固件下载和授权支持；替代型号差异、改造范围、重新验证成本和停机窗口；单一来源、长交期、专用工具/软件或供应商退出的依赖。

若原厂没有公开支持期限，记录unknown/N/V，通过正式渠道索取书面确认，不自行推算。

## 6. 地区供应、售后与备件风险

供应区域必须落实到采购和安装地区，而不是简单记录厂商总部国家。

| 维度 | 可接受证据 | 不足以证明的材料 |
|---|---|---|
| 原厂销售范围 | 原厂区域官网、当地法人/分支机构说明 | 全球集团介绍页 |
| 授权渠道 | 原厂授权经销/服务商目录或书面授权 | 搜索引擎商家列表 |
| 库存与交期 | 有日期、型号、数量和有效期的正式书面确认 | “通常有货”“可询价” |
| 售后服务 | 服务合同、服务范围、响应时间、地点和人员资质 | 仅有服务热线 |
| 备件供应 | 关键备件清单、订货代码、交付承诺和替代策略 | 产品目录仍可下载 |
| 维修/校准 | 明确维修主体、返修流程、校准能力和周期 | 未经确认的第三方承诺 |
| 语言与合规 | 技术支持语言、当地法规/认证和出口限制（适用时） | 仅依据集团总部信息 |

区域信息应记录核验日期和有效期。没有可验证材料时，状态保持not_assessed，不得用品牌知名度代替本地服务能力。

## 7. 风险台账与优先级

### 7.1 风险类别

- 技术兼容风险：接口、参数、软件、工艺或安全不匹配；
- 生命周期风险：停产、支持结束、软件停止维护或备件淘汰；
- 供货风险：单一来源、地区限制、库存不足、交期不确定；
- 售后风险：当地无授权服务、维修周期长、备件不可得；
- 质量风险：批次差异、质量记录不足、验证样本不充分；
- 变更风险：替代导致图纸/BOM/程序/参数/安全文件或认证变更；
- 知识产权/合规风险：软件许可、出口管制、保密和资料使用权不清。

### 7.2 风险登记模板

| 字段 | 内容 |
|---|---|
| risk_id | 项目内唯一编号 |
| machine/configuration | 适用机床型号、配置和版本 |
| component/model | 现用件与候选件的完整订货代码 |
| risk_category | 上述风险类别之一或多个 |
| cause / consequence | 可追溯原因与对质量、交付、安全、成本/停机的影响 |
| evidence_ids | SRC/测试报告/图纸/采购确认记录 |
| likelihood | 发生可能性；无历史或证据时N/V |
| impact | 影响等级；按项目批准尺度定义 |
| detectability | 可探测性；按项目批准尺度定义 |
| risk_rating | 仅在评分尺度、证据和责任人明确后计算 |
| mitigation / contingency | 预防措施、备选方案、恢复方案 |
| owner / due_date | 责任岗位和计划日期 |
| status / review_date | 状态和最近审查日期 |

不得默认给出概率、影响或风险分值。项目尚未批准评分尺度时，使用定性描述并标记not_assessed；不能将N/V当作低风险，也不能用缺失数据计算平均分。

### 7.3 风险处置建议

对影响安全、关键精度、主运动/进给或设备可用性的高后果项目，先设硬性准入门槛，不用低价格或高综合分抵消。单一来源或生命周期风险可通过安全库存、第二来源、长期备件协议、设计标准化或可验证替代方案缓解；措施需结合停机损失和资金约束。对替代件建立回退路径，保留原件参数、软件、图纸和恢复方法；未经批准不得直接修改安全相关配置。风险接受必须记录责任人、有效期限、适用配置和复审触发条件。

## 8. 选型比较与决策流程

**阶段A：需求与硬门槛**
1. 明确机床型号、配置、安装位置、工艺和目标地区。
2. 定义功能边界、必需性能、环境、寿命和安全要求。
3. 列出不可妥协的机械/电气/软件/工艺/安全接口要求。
4. 任一关键硬门槛无证据或不满足时，状态为hold，不进入综合评分。

**阶段B：候选与证据审查**
1. 取得现用件和候选件完整订货代码及版本。
2. 取得原厂图纸、规格书、手册、软件/固件兼容清单和生命周期公告。
3. 逐域建立C0～C4兼容性等级及差异清单。
4. 核验地区销售、授权服务、库存、交期、备件和维修条件。
5. 对来源冲突、版本不一致和缺失项建立待办，不以推测补齐。

**阶段C：验证与批准**
1. 完成设计评审和变更影响分析。
2. 制定机械、电气、通信、软件、工艺及安全验证计划。
3. 在适当环境完成台架/离线测试和目标机床测试。
4. 对精度、热、振动、测量、加工质量、报警/恢复及安全功能进行适用验证。
5. 更新BOM、图纸、程序、参数、维护文件和备件清单。
6. 由设计、控制、电气、工艺、安全、质量和采购责任方按职责批准。

**阶段D：采购与持续监控**
1. 采购订单锁定准确型号、版本、选件、地区和交付条件。
2. 到货核对铭牌、包装、序列/批次、文件版本和合格证明。
3. 记录供应商变更、替代通知、停产公告、质量问题和服务响应。
4. 对关键件设置定期复核和替代预案触发条件。

## 9. 评分框架：先准入，再比较

只有通过硬门槛且有足够证据的候选项，才可进行多维比较。建议维度包括功能/性能满足度、机械接口和改造工作量、电气/通信/软件集成工作量、工艺质量与生产节拍影响、生命周期和备件保障、目标地区服务与维修能力、质量记录与验证充分性、全生命周期成本（须使用正式报价、维护和停机假设）。

权重由具体项目团队根据停机损失、工艺和风险确定，本库不设默认权重。比较结果同时展示原始证据、假设、N/V项和敏感性分析。没有正式报价或可比成本口径时，不填价格、不计算虚构TCO。安全、接口或关键性能硬门槛不满足时，不能由综合得分抵消。

## 10. 项目采购核验清单

- [ ] 需求、机床配置、安装位置和目标地区已冻结；
