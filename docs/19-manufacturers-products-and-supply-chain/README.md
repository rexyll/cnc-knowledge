# 19. 厂商、产品与供应链

**English:** Manufacturers, Products and Supply Chain  
**范围：** 数控机床整机厂、数控系统、伺服驱动、主轴、导轨丝杠、轴承、刀具、传感器及备件供应商和产品目录。

## 本章覆盖内容

- 整机品牌、产品系列、生产地、型号和技术资料入口
- CNC、PLC、伺服、主轴、驱动器、编码器和工业网络厂商
- 机械部件、功能部件、刀具、夹具、液压/气动、润滑和冷却供应商
- 供应商资质、产品生命周期、交期/替代风险和服务网络
