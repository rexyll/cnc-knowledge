## 1. 阅读边界与实体身份

本章把供应链组织按其在机床价值链中的角色区分：

- **整机OEM**：承担整机产品设计/制造并以机床或加工设备系列对外发布产品。OEM身份与具体型号的实际生产法人、生产工厂、销售区域仍需分开核实。
- **CNC/运动控制平台供应商**：提供CNC控制器、PLC/运动控制、伺服驱动、电机或反馈测量产品；其产品可能被机床OEM集成，但不能由供应商目录推断某台机床的实际BOM。
- **机械功能部件供应商**：提供导轨等机床功能部件；供应商目录只能证明其公开产品范围，不能证明具体整机使用该品牌。
- **钣金/特种加工设备OEM**：产品工艺边界与金属切削加工中心不同，应按工艺路线分类，不宜用同一参数表直接比较。

VENDOR记录代表组织身份，BRAND记录（如后续需要）用于品牌归属，PRODUCT记录用于具体产品/型号，MACHINE记录用于整机型号。集团公司、品牌、区域子公司、实际制造法人、经销商和系统集成商不得互相替代。当前15条VENDOR记录沿用既有ID，不因产品品牌或区域法人名称相似而新建重复组织。

### 2.1 整机产品档案如何继续细化

机床系列不应被当作单一型号。后续型号档案至少要记录：官方型号全称/后缀、产品代际、机床结构、轴配置、行程/工作包络、主轴/刀库、控制系统、选件、地区版本、规格发布日期和原厂资料定位。只有原厂明确给出的参数才录入；系列宣传页不够支撑的字段保持待核实。

Mazak的公司资料尤其说明了组织边界问题：Yamazaki Mazak Corporation是世界总部名称，Mazak Corporation是美国法人名称；集团公司列表和生产设施列表是不同维度。不能把美国站点列出的公司资料自动套用于所有国家，也不能把销售/支持据点等同于制造工厂。

### 3.1 控制系统与整机的关系

CNC平台供应商提供控制产品和技术资料，整机OEM负责具体机床的机械、电气、控制柜、PLC逻辑、轴参数、伺服匹配、安全回路、机床数据和调试集成。相同CNC品牌可能被不同OEM以不同选件和接口方式集成；同一整机系列也可能因市场、年份或配置采用不同控制系统。

因此，下列推断均不成立，除非有具体型号/配置证据：

1. 某品牌销售某CNC，不能推出某台机床使用该CNC。
2. 两台机床都使用同品牌CNC，不能推出PLC程序、参数、驱动器、总线和安全接口相同。
3. 控制器产品页列出的最大轴数/功能，不等于某机床实际启用的轴数或同时联动能力。
4. 伺服驱动、电机和编码器来自同一厂商，不代表不同代际或不同订货代码可直接互换。

## 5. 厂商资料、地区服务与供应状态的核验方法

| 信息类型 | 可由官方公开资料支持的内容 | 不能直接推出的结论 |
|---|---|---|
| 企业/集团介绍 | 官方名称、公开业务板块、组织介绍 | 集团内任一法人均为该产品制造商 |
| 产品目录 | 厂商公开展示的产品系列和应用范围 | 当前在售、可订货、库存、交期或特定区域可供货 |
| 生产设施 | 官方明确列出的工厂或生产基地 | 每个型号均在该工厂生产，或可从该厂直接采购 |
| 销售/服务网络 | 页面列出的地区办公室、技术中心、服务入口 | 具体城市的响应时间、备件库存、授权服务资格或服务等级 |
| 规格/技术页 | 指定产品/版本的厂商声明 | 第三方实测、长期可靠性或跨型号/跨版本适用性 |
| 代理/经销商页面 | 代理商自身公开的授权/销售声明 | 代理商是原厂、制造法人或具备所有型号的授权 |

对中国地区采购或维护项目，应另行核实中国法人/授权主体、服务网点地址、工程师资质、备件仓和库存、服务合同、响应时间、保修范围、软件授权及进口/本地化情况。全球“locations”或“support network”不能替代这些项目级证据。

- 产品系列/型号使用PRODUCT记录，整机型号使用MACHINE记录；产品制造关系用MANUFACTURED_BY，分销关系用DISTRIBUTED_BY，供货关系用SUPPLIED_BY，不能用文章索引边代替事实关系。
- 本文与15家VENDOR之间的DERIVED_FROM关系只用于文章内容导航和来源追溯，不表示制造、供货、采购推荐、质量评级、兼容性或地区可用性。
- 供应商状态、停产、交期、价格、库存、授权服务状态均未在本轮评估；没有近期、具体地区和具体型号证据时保持unknown/not_assessed。
