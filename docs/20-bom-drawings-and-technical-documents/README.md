# 20. BOM、图纸与工程技术文档

**English:** BOM, Drawings and Engineering Documentation  
**范围：** 整机/子系统BOM、零件清单、电气BOM、图纸、规格书、手册、技术变更、文档版本和数据关联。

## 本章覆盖内容

- 整机BOM、机械BOM、电气BOM、软件/固件清单和备件清单
- 总装图、零件图、装配图、电气原理图、接线图和气液压图
- 规格书、产品手册、维护指南、安装说明、检测报告和证书
- 文档编号、版本、变更记录、适用机型、来源、版权和生命周期

## 建议正文结构

- `overview.md`：章节总览、概念和分类。
- `architecture.md` / `principles.md`：结构、原理和系统关系（适用时）。
- `specifications.md`：参数、型号、接口和指标（适用时）。
- `procedures/`：设计、制造、安装、操作或维护专题（适用时）。
- `cases/`：工程案例、测试和故障分析（适用时）。
- `ASSET-INDEX.md`：本章在 `resouces/20-bom-drawings-and-technical-documents/` 中的资源索引。
