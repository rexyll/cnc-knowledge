# 08. 伺服、主轴与运动控制

**English:** Servo, Spindle and Motion Control  
**范围：** 伺服驱动器、电机、主轴电机/驱动、编码器、反馈链、轴控制、同步控制和运动性能。

## 本章覆盖内容

- 伺服电机、直线电机、力矩电机、主轴电机和驱动器
- 编码器、光栅尺、旋转变压器及位置/速度/电流反馈
- 电流环、速度环、位置环、前馈、滤波和增益调试概念
- 多轴同步、主从轴、龙门同步、主轴定向和刚性攻丝
