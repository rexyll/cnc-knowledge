# 伺服级联控制：电流环、速度环与位置环

**章节：** CH08 — 伺服、主轴与运动控制  
**主题边界：** 本文解释典型伺服轴的级联闭环信号路径、环路职责、前馈、带宽和调试证据。具体驱动器的参数名称、计算方式、采样周期和调试步骤必须以准确型号/固件手册为准。

## 1. 从位置指令到电机转矩：一条级联控制链

常见的伺服定位轴由位置、速度和电流/转矩三层闭环组成。典型实现中，位置控制器可能位于CNC/运动控制器，速度环和电流环位于驱动器；另一些系统也允许把多个环路配置在驱动器内部。不能只凭“伺服轴”名称推断控制器物理位置或总线周期。

```text
位置指令 θ* / 轨迹速度前馈 ωff / 加速度前馈 αff
             │
             ▼
      位置控制器 Cθ
       eθ = θ* - θfb
             │ 速度指令 ω*
             ▼
      速度控制器 Cω  ◄── 速度反馈 ωfb
             │ 转矩/iq指令
             ▼
      转矩换算 / 限幅 / 前馈 / 扰动补偿
             │ 电流指令 id*, iq*
             ▼
      电流控制器 Ci  ◄── 电流采样 id, iq
             │ 电压指令 vd*, vq*
             ▼
        PWM / 功率逆变器
             │ 三相电压/电流
             ▼
       PMSM / 机械轴系
             │
       编码器 / 输出端反馈
             └──────────返回位置/速度反馈
```

Siemens S200手册以典型级联位置轴为例，说明电流环位于最内层、速度环居中、位置环最外层，并提醒环路带宽与机械刚度、参数耦合有关。[SRC-000320] SINAMICS S120的控制器优化示例使用速度环频率响应定位临界共振，再评估电流设定值滤波和速度控制器参数；该过程属于S120及其特定固件版本的功能说明，不是其他驱动器的通用调参流程。[SRC-000321]

## 2. 电流环：把电流/转矩指令变成受控电磁转矩

### 2.1 PMSM的FOC坐标与转矩关系

在常见的永磁同步电机矢量控制中，三相电流经Clarke/Park变换成为转子同步旋转坐标系中的 (i_d,i_q)。在一种常见的符号约定下，电压模型可写为：

[
v_d = R_s i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q
]

[
v_q = R_s i_q + L_q\frac{di_q}{dt}
+ \omega_e(L_d i_d + \psi_f)
]

其中 (R_s) 为定子相电阻参数，(L_d,L_q) 为d/q轴电感，(psi_f) 为永磁体磁链，(omega_e) 为电角速度。坐标变换方向、反电势符号和解耦项符号必须与驱动器采用的Park变换约定一致。

电磁转矩的一种常见表达式为：

[
T_e=\frac{3}{2}p\left[\psi_f i_q+(L_d-L_q)i_di_q\right]
]

(p) 为极对数。对表贴式PMSM，在 (L_d\approx L_q) 且采用相应控制假设时，常简化为 (T_e\approx\frac{3}{2}p\psi_f i_q)。内嵌式PMSM、弱磁、高饱和或非线性磁链条件下，不能继续把转矩常数视为全工况不变。

### 2.2 电流控制器的职责和限制

电流环常采用d/q轴PI控制，叠加反电势/交叉耦合解耦、限幅、抗积分饱和及PWM调制。其被控对象不仅是电机电感和电阻，还包括电流传感器、ADC采样时序、数字计算延迟、PWM更新与逆变器非线性。

必须分清：
- 电流指令是控制目标，不是实测电流；
- (i_q) 或驱动器“转矩电流”通常是转矩生成分量，不等于直接测得的机械轴转矩；
- 电流采样偏置、增益误差、通道延迟/不同步、逆变器死区和电压饱和都可能引入转矩波动；
- 电流环带宽不能超过采样、PWM、功率器件和电机电气模型所能支持的稳定范围。

电流环的试验记录应保留三相电流原始波形、变换后的d/q电流、指令/反馈差、采样周期、采样触发、PWM频率、滤波和限幅状态。不要只保留驱动器的一个“电流百分比”画面。

## 3. 速度环：把速度误差转化成转矩需求

### 3.1 等效机械模型

以电机轴速度作为状态量的简化机械模型可写成：

[
J_{eq}\frac{d\omega}{dt}
=T_e-T_L-B\omega-T_f(\omega)
]

其中 (J_{eq}) 为折算到电机轴的等效惯量，(T_L) 为外部负载转矩，(B) 为等效粘性阻尼，(T_f) 为摩擦/密封/线缆等非线性阻力。直接驱动省去了中间减速级，但输出台面、夹具、工件、轴承及支承仍决定惯量和机械动态。

速度PI控制器通常依据 (omega^* - \omega_{fb}) 生成转矩或转矩电流需求。速度环需要在指令响应、负载扰动抑制、共振和电流/电压限幅之间折衷。实际速度反馈可能来自编码器位置差分、估算器或驱动器专有观测器；诊断时要记录速度反馈来源和滤波延迟。

### 3.2 前馈与反馈不是同一种功能

- **速度前馈：** 根据期望位置轨迹的导数提供速度参考，减轻位置环在加减速时所需的误差驱动。
- **加速度/转矩前馈：** 根据轨迹加速度和估计惯量计算动态转矩需求，例如简化的 (T_{ff}=J_{est}\alpha^*+B_{est}\omega^*)。如果负载惯量、摩擦或单位换算错误，前馈会产生系统性过补偿。
- **反馈控制：** 根据真实反馈与目标的差值修正扰动和模型误差；前馈不替代反馈闭环。
- **扰动观测器：** 根据名义模型和测量输出估计未建模/外部扰动；其功能和前馈不同，详见CH12专题。

## 4. 位置环：输出位置跟踪与整机轴精度

位置环将指令位置与反馈位置比较，输出速度参考或等效运动需求。常见位置控制器为P型结构，并可叠加速度前馈；实际系统还可能具有双反馈、外部光栅反馈、摩擦补偿、死区处理或专有动态功能。

直接驱动回转轴应明确：
- 电机端编码器测量转子角度，输出端圆光栅测量台面/输出轴角度；两者不是同一测量点；
- 电机端反馈可用于换相/速度/位置控制，输出端反馈可闭合更接近负载侧的位置环，但会受到反馈安装误差、机械结构柔度和通信/采样延迟影响；
- 位置分辨率、编码器系统精度、安装后精度、NC轴定位精度及加工轮廓误差不可互换；
- 跟随误差是控制器内部指令—反馈差值，需与独立计量系统测得的真实轴位置误差区分。

## 5. 环路带宽、机械刚度和稳定性

级联结构通常要求内环响应比外环更快，即电流环通常快于速度环，速度环通常快于位置环。但具体频率关系受电机电气时间常数、采样/通信延迟、惯量、负载、扭转刚度、轴承支承、编码器分辨率和控制实现约束，不存在适合所有机床的固定带宽比。

提高增益可能提升响应速度，却会降低相位裕度或激发结构共振；低刚度、长轴系、大惯量转台和柔性联轴节尤需评估机械动态。Siemens S200文档也提醒：机械刚度较低时，简单提高伺服增益可能引入振动而无法改善响应。[SRC-000320]

调试时建议区分以下证据：
1. **阶跃/轨迹响应：** 上升时间、超调、稳定时间、跟随误差和限幅状态；
2. **频率响应：** 幅值/相位、共振峰、相位裕度/增益裕度（按所用测量定义）；
3. **电流/转矩响应：** 指令与实测电流、限流/电压饱和、周期成分；
4. **机械响应：** 电机端与输出端位移/角度、振动测点和负载变化；
5. **多工况响应：** 空载/负载、正反向、低速/中速、冷态/热态和不同惯量配置。

陷波器、低通滤波或前馈可以改变闭环响应，但不能替代机械故障排查。滤波器自身会引入幅相变化、相位滞后或目标频段抑制，必须在同一配置基线下做回归对照。

## 6. 可追溯的调试顺序

| 阶段 | 先决条件与主要动作 | 验收证据 |
|---|---|---|
| 0. 配置冻结 | 记录电机/驱动/编码器/机械支承身份、固件、参数备份、负载惯量和反馈拓扑 | 配置清单、参数文件哈希/版本、图纸和风险评估 |
| 1. 机械/反馈健康 | 检查定转子气隙、轴承、夹紧释放、编码器安装、信号和接地 | 机械检查表、反馈信号诊断、独立位置基准 |
| 2. 电流环 | 检查电流传感器/采样、相序、电机参数和电压限制；按厂家流程验证闭环响应 | d/q指令与反馈、相电流原始波形、阶跃/频响和限幅状态 |
| 3. 速度环 | 在机械条件确认后识别惯量/共振，按厂家工具调增益/滤波 | 速度阶跃/负载扰动/频响、稳定性和振动证据 |
| 4. 位置环 | 确认反馈位置、速度估计和轨迹时间基准，逐步验证位置响应/前馈 | 跟随误差、定位/重复定位、输出端独立测量 |
| 5. 前馈/补偿 | 参数辨识后逐项启用速度、加速度、摩擦或周期扰动补偿 | 补偿前基线、参数版本、正反向/多负载回归 |
| 6. 整机验证 | 与机床联锁、轨迹/插补和工艺负载条件结合 | 单轴/多轴验收报告、报警和安全记录 |

此表是证据顺序，不是可替代设备手册的现场操作程序。任何改变参数、禁用反馈/保护、拆除夹紧或带负载运动的操作均须由合格人员在经批准的风险控制与设备程序下执行。
