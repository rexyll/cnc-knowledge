# 伺服速度/加速度前馈与陷波、低通滤波器联合设计

> 本文讨论轨迹前馈与反馈滤波的功能分工及相互影响。数值只来自本仓库合成两/三惯量模型，不是机床参数、驱动器默认值或现场调试建议。

## 1. 速度前馈与加速度/转矩前馈

设轨迹规划器提供位置参考 \(\theta_r(t)\)，并能同步提供解析或离散一致的导数：

\[
\omega_r=\dot\theta_r,\qquad \alpha_r=\ddot\theta_r
\]

位置环速度命令可写为：

\[
\omega^\* = K_{p\theta}(\theta_r-\theta_{fb})+\omega_{ff}
\]

速度环转矩指令在反馈PI之外可叠加加速度/转矩前馈：

\[
T_{cmd}=K_{p\omega}(\omega^\*-\omega_{fb})+x_I+
J_{rigid,est}\alpha_r+B_{rigid,est}\omega_r
\]

速度前馈用期望轨迹速度减轻位置环在加减速阶段产生跟随误差的需要；加速度前馈则依据模型估算加速所需转矩。它们都不是反馈：负载转矩变化、摩擦误差、参数偏差和外部扰动仍须靠闭环修正。应优先使用轨迹规划器已有的解析速度/加速度，不要直接对含编码器量化、噪声或延迟的位置测量做未经滤波的数值微分。

### 1.1 必须区分刚体惯量与扭转模态约化惯量

对本项目直接耦合、低频时两侧近似相同角加速度的两惯量轴：

\[
J_{rigid}=J_m+J_l,\quad B_{rigid}=B_m+B_l
\]

因此刚体运动的惯量/阻尼前馈应使用总刚体惯量和相应阻尼。在相对扭转坐标下，约化惯量为：

\[
J_{red}=\frac{J_mJ_l}{J_m+J_l}
\]

它用于求相对扭转模态，例如：

\[
\omega_r=\sqrt{\frac{K_s}{J_{red}}}
=\sqrt{K_s\frac{J_m+J_l}{J_mJ_l}}
\]

不能把 \(J_{red}\) 当成整轴共模加速度前馈所需的总惯量。更复杂传动链须将各负载惯量按传动比平方折算到选定轴侧，并明确反馈位置和齿轮间隙/柔性。

## 2. 陷波器：压制已识别的窄带模态

连续二阶陷波器可写为：

\[
N(s)=\frac{s^2+2\zeta_z\omega_n s+\omega_n^2}
{s^2+2\zeta_p\omega_n s+\omega_n^2}
\]

其中 \(\omega_n=2\pi f_n\) 为中心角频率，\(\zeta_p\) 决定极点阻尼和陷波宽度，\(\zeta_z/\zeta_p\) 决定中心频率增益。对本文二阶形式，常用近似 \(Q\approx 1/(2\zeta_p)\)。减小中心增益或增大宽度会改变幅相响应，并非只在共振点“删掉一条峰”。

陷波设计的输入应来自可追溯的对象频响、模态识别和工况身份。负载惯量或机械状态改变会移动共振频率；固定中心频率的陷波在失谐后可能效果下降，甚至在原共振附近留下反共振和额外相位变化。[SRC-000341] 该结论是一般两惯量模型说明，不代表本项目合成频率适用于任何具体机床。

### 2.1 数字化实现

控制器最终运行于离散采样系统。连续陷波器离散化方法包括ZOH、Tustin、匹配极零等；当关注频率靠近数字系统有效频带时，不同方法的频率响应可能有明显差别。双线性变换可在目标陷波频率预畸变，使数字滤波器的陷波中心与设计目标对齐；离散后仍须直接计算数字频响并与连续设计比较。[SRC-000342][SRC-000343]

本轮在0.5 ms采样周期下，使用预畸变双线性变换构造三个二阶SOS段，中心频率42、70、94 Hz，极点阻尼比0.12、中心幅值增益0.05（约−26.02 dB），对应 \(Q\approx4.17\)。这些频率是覆盖合成模型模态的研究值，不是通用推荐，也不是自适应陷波器。固定陷波器的风险恰在于冷热/负载/结构状态变化后可能失谐。

## 3. 低通滤波器：噪声抑制与相位滞后的交换

本轮把一阶Butterworth低通放在电机速度测量反馈路径，截止频率150 Hz。连续一阶近似：

\[
H_{lp}(s)=\frac{\omega_c}{s+\omega_c}
\]

其相位为：

\[
\phi(f)=-\tan^{-1}(f/f_c)
\]

以 \(f_c=150\) Hz 估算，在12 Hz处约−4.57°，65 Hz处约−23.43°，70 Hz处约−25.02°，94 Hz处约−32.07°。这意味着低通不仅改变高频幅值，也改变速度环反馈相位。低通平滑/抑噪存在与时间常数同量级的动态滞后；具体离散滤波器还需检查数字相位和群延迟。[SRC-000344]

所以不能只凭噪声谱或幅频曲线选截止频率。应同时比较速度环全部增益/相位交越、滤波后噪声、跟随误差、扰动响应、离散采样和反馈链总延迟。

## 4. 滤波器放置位置决定它影响什么

本轮对比两种滤波位置：

- 陷波器位于速度PI输出/转矩命令通道。它能降低该通道通过特定频率的命令分量，但也会削弱反馈控制器在同一频率生成的校正转矩，因此可能恶化外部负载扰动抑制。
- 低通位于电机速度反馈测量路径。它主要衰减反馈噪声，但会引入反馈相位滞后并改变闭环裕度。

滤波不能脱离注入点讨论。对轨迹指令中已知的周期纹波、机械对象本身的共振和施加在负载端的外部扰动，这三类信号的传递路径不同。一个滤波器对前者有利，不保证对后两者同样有利。前馈也可能绕过滤波器，需要把完整信号路径画清楚。

## 5. 本仓库合成模型及验证矩阵

沿用前一轮四种对象参数族，计算的无阻尼柔性模态频率为：

| 对象 | 弹性模态频率 |
|---|---|
| nominal_cold | 72.934 Hz |
| heavy_load_cold | 68.223 Hz |
| heavy_load_hot | 64.722 Hz |
| three_mode_reference | 41.906 Hz、94.079 Hz |

频率只是由合成 \(J,K\) 矩阵的广义特征值计算；没有测量温度，也没有拟合真实热漂移定律。固定陷波中心的选择对应覆盖多模态对象集合的研究案例，而不是单一设备最优值。

联合验证包含：

1. 无前馈、速度前馈、速度+加速度前馈；
2. 无滤波、陷波、速度反馈低通、陷波+低通；
3. 1 Hz、0.04 rad正弦轨迹，以及在各对象模态处叠加0.0002 rad的小幅参考纹波；
4. 负载端在1.0～1.30 s注入各模态频率的0.015 N·m合成周期转矩扰动；
5. 0.5 ms采样，1 ms一阶转矩执行器，±1 N·m转矩限幅、±1.5 rad/s速度参考限幅，30 ms反算抗积分饱和；
6. 对惯量/阻尼前馈分别使用名义估计、工况匹配估计和20%低估，检查模型偏差影响。

## 6. 结论和工程使用限制

- 速度前馈和加速度前馈主要减少可预测的轨迹加减速误差；不替代反馈，也不自动抑制外部负载扰动。
- 陷波适合在已识别窄带模态上评估，但固定频率会受负载/结构变化影响；若考虑自适应陷波，需另外验证频率估计、误识别、更新速率和时变闭环稳定边界。[SRC-000345]
- 速度反馈低通会平滑测量噪声，同时引入相位/群延迟。其截止频率必须结合真实采样、反馈噪声和交越频率确定。
- 多交越点时必须保留每个交越对应的裕度和频率；经典SISO GM/PM只描述指定单环断点，不能代替完整MIMO disk margin。[SRC-000340]
- 本轮只有合成SISO两/三惯量模型，没有真实驱动器电流环、电机电磁模型、逆变器开关、总线抖动、编码器量化、多轴耦合、HIL、台架或实机验证。

本文中的滤波中心、截止频率、控制器增益和所有仿真结果均不可直接复制到生产机床。真实整定必须基于准确设备/固件、实际测量链、批准的试验程序、参数备份与回退方案。
