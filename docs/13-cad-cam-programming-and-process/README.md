# 13. CAD/CAM、数控编程与加工工艺

**English:** CAD/CAM, NC Programming and Machining Process  
**范围：** CAD/CAM/CAPP、NC程序、G/M代码、工艺规划、切削参数、后处理、仿真和加工应用。

## 本章覆盖内容

- 零件几何、工艺规划、工序/工步、装夹和加工路线
- G代码/M代码、坐标系、刀补、宏程序、子程序和循环
- CAM刀路、后处理器、机床仿真、碰撞检测和程序验证
- 切削速度、进给、切深、刀具寿命、表面质量和加工效率
