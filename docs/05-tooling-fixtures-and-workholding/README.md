# 05. 刀具、工装与工件装夹系统

**English:** Tooling, Fixtures and Workholding  
**范围：** 刀具、刀柄、接口、刀库、自动换刀、夹具、卡盘、工作台、工件定位夹紧、测头和刀具/工件测量。

## 本章覆盖内容

- 刀具材料、几何参数、涂层、磨损和寿命
- 刀柄、主轴接口、拉刀机构、刀库、换刀臂和工具管理
- 卡盘、夹具、虎钳、压板、零点定位、真空/液压/气动夹紧
- 对刀仪、工件测头、刀具测量、工件基准和装夹精度
