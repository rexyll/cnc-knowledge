# 04. 零部件、材料与制造工艺

**English:** Components, Materials and Manufacturing  
**范围：** 机床零部件目录、零件规格、材料牌号与性能、热处理、表面处理、加工制造工艺及部件可替代关系。

## 本章覆盖内容

- 零部件分类、名称、图号/型号、数量、位置、功能和制造商
- 金属、铸铁、钢、铝合金、复合材料、工程塑料和功能材料
- 化学成分、力学性能、物理性能、热学性能、疲劳和耐磨指标
- 铸造、锻造、焊接、热处理、精密加工、表面处理和质量检测
