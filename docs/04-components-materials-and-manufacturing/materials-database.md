> 知识ID：KNOW-000017  
> 主章节：CH04  
> 版本：0.1（首轮标准框架）  
> 核验日期：2026-11-22

> 适用范围：数控机床结构件、传动件、主轴/轴承相关件、耐磨件、钣金件、辅助系统零件及其材料数据管理。

## 1. 建设目标与数据层级

材料数据库需要将“材料是什么”“依据哪个标准”“具体交付状态是什么”“性能如何测得”分开保存。推荐采用四层数据结构：

1. **材料族（family）**：灰铸铁、球墨铸铁、非合金结构钢、铝及铝合金、工程塑料、纤维增强复合材料、硬质合金/陶瓷等。仅用于分类检索，不构成材料牌号。
2. **标准牌号/规范（designation）**：发布机构、标准编号及版本、牌号原文、材料形态/产品形式、规范适用范围。一个牌号必须属于明确的标准体系。
3. **材料状态（condition）**：交付状态、热处理/回火状态、加工/成形状态、厚度或截面范围、表面状态、批次/炉号等。相同牌号的不同状态不得合并成一个性能记录。
4. **性能结果（property observation）**：单项指标的数值/上下限、单位、测试方法版本、试样形状尺寸/方向/取样位置、测试温度、试验条件、实验室/报告和来源定位。规范保证值、厂商典型值、批次实测值必须分开。

本项目内部ID（未来的MAT-xxxxxx）只负责稳定标识数据库记录；标准牌号、厂商牌号、炉批号和质保书编号均作为外部标识字段保存。未确认标准牌号或材料状态时，不创建已核验MAT实体。

### 2.1 GB/T 9439-2023：灰铸铁件的数据采集边界

国家标准官方目录确认该版现行，全部代替GB/T 9439-2010；其采标关系为非等效采用ISO 185:2020。官方标准项目摘要说明，该产品标准覆盖牌号、技术要求、取样、试验、检验、标识、包装和储运；适用范围以砂型或导热性相当的铸型生产的普通及低合金灰铸铁件为主，不适用于灰铸铁管、管件、配件、接头及连续铸造灰铸铁件。该官方项目摘要还记录了本次修订新增单铸试样、并排试样和附铸试样术语，以及对相应试样强度要求的修订。这里引用的是官方标准项目的范围/修订摘要，不替代GB/T 9439-2023正式文本条款。SRC-000110、SRC-000117。

因此，灰铸铁性能数据不能只记录“HT牌号 + 抗拉强度”。每条规范性能记录至少需要保留：

- 标准版次与牌号原文；
- 试样类别（单铸、并排、附铸或铸件本体），以及试样几何/直径（标准规定时）；
- 铸件主要壁厚、试样所代表的壁厚区间和取样位置；
- 抗拉强度的下限/上限及对应试样类别；
- 若采用硬度验收，记录硬度标尺、试验力、测点/测区、主要壁厚和供需双方约定；
- 订货协议指定的验收指标、抽样/复验要求、检验报告与铸件批次。

上述字段是本项目的采集要求，不是对标准条款数值的转述。尚未取得可合法核验的正式标准文本前，不录入HT各牌号的数值表，也不将单铸试棒值当作任意铸件截面的保证值。

### 2.2 GB/T 1348-2019：球墨铸铁件的数据采集边界

国家标准官方目录确认GB/T 1348-2019现行，全部代替GB/T 1348-2009；2025-11-03复审结论为继续有效，并注明修改采用ISO 1083:2018。该标准归口于全国铸造标准化技术委员会，类别为产品标准。SRC-000111。

球墨铸铁牌号数据采集应独立于灰铸铁体系，至少逐项核验：

- 标准原始牌号及所有后缀/附加符号，不以QT主字符串替代完整牌号；
- 材料类别/基体组织或特殊性能类别（仅在标准明确规定时记录）；
- 试样类型、取样位置、铸件壁厚/截面区间及热处理/交货状态；
- 抗拉强度Rm、规定塑性延伸强度Rp0.2、断后伸长率A，以及标准要求或订货约定的硬度/冲击指标；
- 每项指标各自的试样条件、温度、单位、验收属性、表号/条款和批次追溯。

不能把牌号名称中数字的常见解释当作完整性能表，也不能用同名QT牌号在其他标准、行业标准或企业规范中的数据替代GB/T 1348-2019。官方目录只确认标准身份、版次、状态和采标关系；具体牌号表、壁厚分档及保证值必须依据正式标准文本逐项复核。

### 2.3 铸铁牌号数据录入门槛

本轮不创建具体HT/QT材料实体。下一阶段只有在正式标准文本合法可用、能定位具体表号/条款并核对试样类别和适用壁厚后，才建立牌号级MAT主记录及独立MPR性能记录。若只有材料供应商页面、经销商数据库或行业文章，则最多登记为待核验线索，不能升级为标准保证值；制造商质保书只支持对应批次和状态。

## 3. 标准体系与牌号映射规则

### 3.1 牌号的完整身份

材料记录至少应包含：标准发布机构/国家或地区体系（ISO、EN、ASTM、GB、JIS等）；标准编号、年份/版次、修订/勘误及核验日期；牌号原文（保留大小写、连字符、后缀和状态符号）；标准中的材料类别、产品形态、尺寸/厚度范围；交货状态、热处理状态、表面状态和附加质量要求；牌号定义的性能类别及其测试试样条件；供应商/制造商质保书中的实际牌号、炉批号和检验结果（如有）。

不能只录“HT250”“45钢”“6061”“PA66”等孤立字符串。字符串可能来自不同标准、旧版规范、厂商内部命名或俗称，必须先确认来源体系与完整后缀。

### 3.2 跨标准映射不等于材料等同

不同体系的牌号对照分为以下状态：

| 映射状态 | 允许表达 | 最低证据 |
|---|---|---|
| exact_same_standard | 同一标准体系内同一牌号/版本 | 标准正文及版本确认 |
| formally_equivalent | 标准明确给出的等同采用/正式替代 | 标准发布机构的等同关系文件 |
| conditional_comparison | 在限定产品形态、厚度、状态和性能项下可比较 | 两边标准完整条款与逐项对照 |
| approximate_reference | 仅作为检索线索或近似参考 | 明确列出差异和未覆盖性能 |
| not_equivalent | 已知不可等同或适用范围明显不同 | 标准范围/技术条件证据 |
| unknown | 证据不足 | 不作结论 |

禁止仅凭网上“对照表”、相近抗拉强度、相似硬度或常见叫法把ISO、EN、ASTM、GB、JIS牌号写成一一等同。即使强度等级接近，也必须核对化学成分、产品形态、厚度/截面、热处理状态、冲击要求、取样位置、检验规则和交货文件。

### 3.3 版本与状态

标准状态采用独立字段：published_current、published_under_revision、withdrawn、replaced、draft、unknown。记录当前状态时以发布机构官方目录为准；标准全文中的技术要求仍以合法取得的对应版本为准。若新版正在制定，不得提前将草案要求当作现行标准。

本轮已识别：ISO 148-1:2016官方目录仍显示已出版，但已有ISO/FDIS 148-1进入批准流程；因此数据库应保留2016版记录并标注修订中，不应提前把FDIS当成已发布标准。

## 4. 性能字段模型

### 4.1 化学成分

建议字段：元素符号、质量分数下限/上限、单位（通常为质量百分数）、分析类型（炉前/熔炼分析、炉次分析、成品分析）、取样位置、分析方法、允许偏差、标准条款和报告编号。

每个元素分别存储上下限，不把范围中值当成保证值。若标准对某类材料以机械性能为主要分类指标、并未规定固定化学成分，不应自行补入“典型成分”作为标准要求。灰铸铁ISO 185的范围说明即强调其分类特征与抗拉强度/硬度有关，不能据此推造固定成分表。

### 4.2 力学性能

常见字段包括：抗拉强度Rm、规定塑性延伸强度Rp0.2、屈服强度Re、断后伸长率A、断面收缩率Z、弹性模量E、硬度（HBW/HV/HRC等）、冲击吸收能量K、疲劳强度/疲劳寿命（须定义载荷谱和统计方法）、断裂韧度等。

每条数据必须同时记录：试验方法及标准版本；试样类型、尺寸、标距、取样方向和位置；材料交付/热处理状态及厚度/截面；测试温度、加载/应变速率（适用时）、冲击试验温度和缺口类型（适用时）；单位、统计口径、样本数、单值/平均值/最小保证值；测试报告、实验室、日期和来源定位。

硬度值不能脱离试验标尺、载荷、压头、试样厚度和表面状态；未经适用换算标准和条件核验，不得将HB、HV、HRC直接互换。

### 4.3 物理、热学与耐磨性能

按实际用途逐项登记密度、热膨胀系数、热导率、比热容、电阻率、磁性能、摩擦系数、磨损率、耐腐蚀性等。必须注明温度区间、材料方向、环境介质、表面状态、载荷/速度、对偶材料、润滑条件和测试方法。没有统一方法或测试条件时，数据只作为特定试验记录，不生成通用牌号属性。

复合材料尤其要区分纤维/增强体类型、体积分数或质量分数、铺层/织物结构、纤维方向、基体、固化状态和试样取向；各向异性材料的纵向/横向数据不可合并。塑料数据要记录含水率、调湿状态、试样制备、成型方向、温度和试验速度等影响因素。

## 5. 试样、热处理和状态管理

### 5.1 状态不是备注

热处理状态必须使用可追溯的规范/制造商原始符号，并记录工艺规范版本、适用部位、批次和检验报告。不得从硬度值反推淬火、回火、渗碳、氮化或时效状态；不得把同牌号不同热处理状态合并为一条性能记录。

对钢材交货状态，诸如热轧、正火、热机械轧制等状态标识，应按具体产品标准原文记录。EN 10025-2:2019对产品形式、厚度范围和交货状态有适用约束，不能脱离这些条件引用某个钢级的性能表。

### 5.2 试样信息

每个性能观测记录以下适用字段：取样对象（独立铸造试棒、附铸试样、从铸件切取、板材/棒材/型材/锻件或注塑/挤出试样）；取样位置（产品头尾、厚度方向、表面/心部、铸件壁厚/关键截面等）；方向（纵向/横向/短横向、轧制方向、纤维方向/铺层方向）；试样几何（标准试样类型、尺寸、标距、缺口形状/尺寸）；状态（交货状态、热处理、调湿/含水状态、表面加工状态）；测试条件（温度、湿度、加载速度/应变速率、载荷/压头/标尺、环境介质）；结果（单值、均值、最小/最大值、离散性、样本数和不确定度，如有）。

铸铁的试棒强度不能简单视为铸件任意截面强度。ISO 185明确区分铸样、经供需双方约定的铸件取样和硬度表征；ASTM A48也提示铸件某些截面性能可能与标准试棒值不同。因此数据库必须保留试样来源和铸件壁厚/冷却条件相关信息。

## 6. 数据记录和质量控制

### 6.1 文件与数据表

- [材料标准与牌号体系映射表](../../resouces/04-components-materials-and-manufacturing/materials-standard-map.csv)：首轮标准入口、范围摘要、状态与缺口。
- [CH04字段字典](../data-model/chapter-dictionaries/CH04.csv)：材料主数据与性能观测字段。
- [材料主记录模板](../data-model/templates/material-master.template.json)：用于后续创建具体MAT实体。
- [材料性能观测模板](../data-model/templates/material-property-record.template.json)：用于登记标准保证值、厂商声明或批次实测数据。

模板是数据结构，不是实际材料记录；本轮未创建虚构的MAT牌号实体或性能数值。

### 6.2 数据来源等级与数据属性

必须区分来源权威等级和数据性质。标准发布机构用于支持标准编号、范围和规范要求；材料制造商数据表/质保书用于支持该制造商特定产品、批次和交付状态；独立实验室报告用于支持对应试样和测试条件下的实测结果。二手对照表只能作为检索线索。

性能数据属性建议采用：normative_minimum / normative_range（标准规定的下限/范围）；manufacturer_declared（材料制造商公开声明）；batch_test_result（指定炉批/批次的质保书或检验报告）；independent_test_result（独立实验室测试）；engineering_estimate（明确假设的工程估算，不得伪装成实测）；unknown（未核实）。

### 6.3 自动/人工质量检查

1. 材料ID、标准编号、版次和牌号原文必须唯一可追溯。
2. 所有性能数值必须有单位、测试方法、标准版本和试样/状态条件。
3. 上下限字段必须满足下限不大于上限；量纲和单位转换须保存原值、换算值和换算规则。
4. 标准规定值、厂商典型值和批次实测值不得放入同一统计字段。
5. 同一牌号不同状态、厚度、方向、取样位置和测试温度不得无条件合并。
6. 牌号映射必须有独立状态、证据和差异说明；approximate_reference不等于兼容或替代。
7. 无法定位到标准表号/条款、质保书页码/报告编号的数据，保持待核实，不进入已核验数据集。

## 7. 机床应用中的材料关联边界

材料数据可以支持结构设计、热稳定性、耐磨/疲劳评估和制造工艺分析，但不能单独决定零件选材或证明机床性能。典型应用分析需同时考虑零件功能、受力/振动、热环境、润滑介质、腐蚀/污染、制造路线、热处理变形、加工余量、尺寸稳定性、维修与成本。

床身/立柱材料不能仅凭“常用灰铸铁”推断具体机型采用牌号；丝杠、导轨、轴承、主轴和齿轮材料需由部件制造商规范或机床图纸确认；防护罩/拖链/刮屑板等聚合物或复合材料也需明确商品牌号、阻燃/耐化学性、温度和机械性能要求。材料族描述不是OEM BOM事实。
