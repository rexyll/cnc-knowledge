# 数控机床零部件分类与主数据规范

> **任务：** CH04-T001  
> **版本：** 1.0  
> **知识边界：** 本文建立跨机型可复用的零部件分类和数据记录规则，不提供任何未取得图纸/BOM的具体机床零件清单、图号、数量或材料结论。

## 1. 目的与建模边界

数控机床零部件数据必须同时回答三个不同问题：

1. **它是什么：** 零件/装配件的身份、类别、功能和结构层级。
2. **它属于哪里：** 所属整机型号、配置、子系统、装配位置及BOM版本。
3. **它有什么属性：** 图号、规格、材料、制造商、检验要求、来源和有效版本。

本库使用 `PART` 表示具有可独立管理身份的物理零件或装配件；使用 `PRODUCT` 表示厂商商品化产品型号/系列；使用 `SUBSYS` 表示功能或物理子系统；使用 `BOM` 表示特定整机/子系统配置下的层级物料清单；使用 `MAT` 和 `PROCESS` 分别表示材料及工艺。它们不可互相替代。

例如，某厂商滚动导轨产品系列属于 `PRODUCT`；某一具体机床图纸中定义的导轨安装座属于 `PART`；“进给轴”属于 `SUBSYS`；该机型某配置下的导轨、滑块、螺栓及安装座数量和位号由 `BOM` 表达。没有型号级证据时，不得把典型组成写成某台机床的真实BOM。

本项目的分类树是面向数控机床知识整理的**项目级参考分类**，不是ISO、IEC或任何OEM发布的强制分类，也不意味着所有机型都包含所有类别。

## 2. 零部件分类树

分类采用“功能域 → 部件族 → 零件/装配件”的三级主路径。必要时增加子类，但不得仅为某一厂商的营销命名创建通用类别。

| 一级功能域 | 二级部件族示例 | 典型对象（示例仅说明类别） | 主要管理关注点 |
|---|---|---|---|
| 结构与承载 | 基础/床身、立柱/横梁、滑鞍/滑枕、壳体/支架 | 床身、立柱、主轴箱体、支撑座 | 材料状态、结构基准、连接界面、变形/应力证据 |
| 直线运动与进给 | 导向副、滚动/滑动支承、丝杠副、齿轮齿条、联轴器 | 导轨、滑块、丝杠、螺母、轴承座 | 规格、精度等级、预紧/配合、润滑、安装接口 |
| 主轴与回转 | 主轴轴系、轴承、夹紧/松刀、回转传动、制动/夹紧 | 主轴、轴承组、拉刀机构零件、回转台零件 | 转速/载荷边界、热状态、动平衡、接口和检验依据 |
| 刀库与自动换刀 | 刀库结构、换刀臂、驱动/凸轮、刀具交换定位 | 刀库链节、刀臂、定位销、支架 | 机型配置、运动包络、定位、互锁接口 |
| 工作台与工件支承 | 工作台、托盘、回转工作台、夹紧/定位结构 | 台面、托盘基座、夹紧元件 | 基准、承载、定位接口、工件/夹具边界 |
| 润滑与介质 | 润滑泵/分配、管路接头、过滤、冷却/换热 | 泵、分配器、过滤器、管接头、换热器 | 介质兼容性、压力/流量范围、污染等级、维护 |
| 液压与气动 | 动力源、阀组、缸/执行器、蓄能与管路 | 液压缸、阀、气缸、蓄能器、软管 | 介质、额定范围、密封、储能与隔离风险 |
| 排屑与防护 | 排屑输送、刮屑/导屑、防护罩、门/护板 | 输送链、刮板、伸缩护罩、钣金护板 | 切屑形态、运动干涉、密封、防护和检修边界 |
| 电气与控制硬件（边界项） | 安装支架、柜体结构件、线缆支撑和专用安装件 | 电气柜、安装板、线缆拖链支架 | 与CH06～CH10及PRODUCT记录分工，避免重复建档 |
| 紧固与标准件 | 螺栓/螺母、销、键、垫圈、挡圈、密封件 | 标准紧固件、定位销、密封圈 | 标准号、规格、强度/材料等级、批次和防松要求 |
| 消耗与易损件 | 过滤、密封、刮屑、润滑及维护更换件 | 滤芯、刮片、密封件、皮带 | 适用型号、寿命口径、维护周期来源、替代验证 |

**分类原则：**

- 一个实体只选择一个主分类路径；交叉用途通过标签、关系或适用范围表达，不复制实体。
- 分类路径描述“是什么”，安装位置描述“装在哪里”，所属子系统描述“承担什么功能”，三者分开记录。
- 同一零件在不同机型中复用时，零件身份可复用，但机型实例、数量、位号、装配关系和有效版本必须放在BOM/配置上下文中。
- 采购件的厂商型号与OEM内部图号同时存在时，分别记录，不把两种编号拼成一个不可追溯的主键。
- 成套装配件可登记为PART，并通过BOM层级表达其子件；不能因其包含多个零件就将其降格为PRODUCT。

## 3. 零件身份与唯一编码

### 3.1 本库ID与外部编号分离

本库为每个PART分配永久唯一的 `PART-六位序号`。该ID是知识库内部主键，不替代以下外部标识：

- OEM物料号/零件号（OEM part number）
- 设计图号/工程图号（drawing number）
- 图纸修订版（drawing revision）
- 标准件标准号及规格代码
- 供应商订货代码/商品型号（supplier order code）
- 维修备件号或售后编码

外部编号必须同时记录编号所有者/发布组织、适用产品/机型、版本和有效期。不同组织可能使用相同字符串编号，不能仅凭字符串判断为同一零件。

### 3.2 零件身份判定

满足以下一项或多项且有证据时，可建立独立PART记录：存在独立物料号或图号；在BOM中有独立位号/数量；可独立采购、制造、检验或维修更换；具有独立规格或版本控制。

仅为概念功能、没有可识别物理身份的对象应留在SUBSYS/术语/文章层，不得虚构PART。商品化产品目录项优先登记为PRODUCT；只有当具体机床BOM或图纸将其作为物理装配项引用时，才建立对应PART，并通过明确关系关联产品型号。

### 3.3 变更和去重

- 同一编号但修订版不同：通常保留同一零件身份并记录revision/effectivity；若接口、功能或互换性发生身份级变化，需评估是否新建PART。
- 不同编号但原厂明确声明完全替代：保留新旧记录并建立有证据的替代关系；不能仅因尺寸相似就合并。
- 别名、旧图号和供应商订货号进入aliases或外部标识字段，必须标明编号类型及所有者。
- ID一经分配不复用；合并记录保留旧ID和跳转关系，历史BOM引用不得被静默改写。

## 4. 零件主数据字段

字段分为身份、分类、配置、技术属性、供应、质量、追溯和生命周期八组。具体字段定义见 [CH04数据字典](../data-model/chapter-dictionaries/CH04.csv)，可复制使用的空白记录结构见 [PART主数据模板](../data-model/templates/part-master.template.json)。

### 4.1 最小字段集

| 字段组 | 核心字段 | 录入规则 |
|---|---|---|
| 身份 | entity_id、canonical_name、part_number、number_owner、drawing_number、revision | 内部ID唯一；外部编号必须注明所有者/编号体系 |
| 分类 | classification_path、part_family、part_role、aliases | 采用受控分类；别名不作为唯一键 |
| 归属 | machine_model_id、configuration_id、parent_part_id、subsystem_id、installation_location | 机型/配置/父件必须引用已登记实体或配置记录；未知项留空 |
| 数量 | quantity、quantity_unit、bom_item_ref | 数量和位号属于特定BOM上下文，不能当作全局零件固有属性 |
| 技术 | material_id、key_dimensions、interfaces、tolerance_refs、surface_treatment、heat_treatment | 关键尺寸、公差和材料状态必须关联图纸/标准/来源 |
| 制造/供应 | manufacturer_id、supplier_ids、supplier_order_code、make_or_buy | 制造商与经销商/供应商角色分开 |
| 质量 | inspection_characteristics、inspection_method、acceptance_reference、traceability_lot | 检验项目、方法、限值需有适用文件；未核实不填数值 |
| 追溯 | source_ids、document_refs、evidence_level、verification_status、validity | 记录来源版本、适用范围、核验日期和权利状态 |

### 4.2 条件字段和空值语义

- `unknown`：已确认需要该信息，但目前未知。
- `not_applicable`：经核验，该字段对该对象不适用。
- `not_provided`：来源文件没有提供该信息。
- `not_verified`：已有声明或数据，但尚未核实。
- 空值/null：尚未录入或尚未判断；不得将其解释为“无”或“零”。

涉及尺寸、质量、材料性能、转速、载荷、压力、流量、精度和寿命的字段必须有单位、条件、来源和版本。对温度、载荷、试样方向、热处理、表面状态等影响指标的条件，不得省略。

## 5. 关系和跨章节职责

| 关系/实体 | 主要用途 | 主归属章节 |
|---|---|---|
| SUBSYS —HAS_PART→ PART | 表达已证实的子系统零件组成；必须限定具体机型/配置或明确通用参考层级 | CH04（零件）/CH03（子系统） |
| PART —PART_OF→ SUBSYS/PART/BOM | 表达物理归属或装配层级；与HAS_PART方向一致择一维护，避免重复双边 | CH04/CH20 |
| PART —USES_MATERIAL→ MAT | 记录零件指定材料、部位、状态、批次/适用版本 | CH04 |
| PART —MANUFACTURED_BY→ VENDOR | 仅在图纸、铭牌、原厂资料或可追溯采购记录支持时建立 | CH04/CH19 |
| PART —PROCESSED_BY→ PROCESS | 记录有证据的制造/热处理/表面处理工艺；实际工艺卡归CH16/CH20 | CH04/CH16 |
| PRODUCT ↔ PART | 关联商品化型号与OEM零件身份；必须说明装配/采购关系和具体适用条件 | CH04/CH19 |
| BOM —HAS_PART→ PART | 在BOM中表达数量、位号、层级、选配和有效版本 | CH20 |
| PART ↔ INTERFACE / FAULT / PROC | 机械接口、故障模式和维修程序分别由CH03/CH18/CH16～CH17维护 | 跨章节 |

本章不抢占CH20的BOM主数据职责，不把CH03的抽象子系统示意转换为未经核验的HAS_PART事实，也不把CH19的厂商产品目录自动等同于某OEM零件。关系记录必须有来源和配置限定；没有图纸、BOM、原厂手册或工程记录时，只能在文章中作为“典型类别/候选项”描述。

## 6. 证据等级与录入门槛

建议对每条PART记录及关键属性独立记录证据状态：

| 状态 | 证据基础 | 可允许的表达 |
|---|---|---|
| E0 — 未识别 | 仅为概念或口头描述 | 不创建正式PART实体 |
| E1 — 候选 | 二手目录/照片/未核实清单 | candidate/in_review；不得宣称适配或组成 |
| E2 — 文档识别 | 原厂图纸、BOM、手册或规格书可定位到编号/版本 | 可建立PART身份和文件明确给出的字段 |
| E3 — 交叉核验 | 多份一致文件、采购/检验记录或可追溯实物铭牌 | 可提升对应属性核验状态，仍需标注对象/版本 |
| E4 — 现场验证 | 指定机床实例、配置、测量/检验记录可追溯 | 仅对该实例和工况声明已验证，不自动推广到同系列全部设备 |

E0～E4是本项目内部数据治理标签，不是ISO/IEC认证等级或行业标准等级。某一字段可达到E3，而同一零件的寿命或互换性仍为未知；不得用整条记录的一个“verified”覆盖所有字段的证据差异。

## 7. 数据质量校验清单

1. **身份唯一：** PART ID唯一；外部编号带所有者、类型和版本，排查重复/别名冲突。
2. **分类有效：** 主分类路径来自受控分类树；未知类别先提议扩展，不随意创造近义分类。
3. **配置完整：** 机型、选配、轴配置、安装位置和BOM修订版明确；通用示例与具体实机数据分离。
4. **量纲完整：** 数值有SI单位、基准、条件、有效位数及来源；尺寸/公差不脱离图纸修订版。
5. **材料可追溯：** 材料牌号、标准体系、状态、热处理、部位和批次分别记录；不得由外观或用途推断牌号。
6. **供应角色明确：** 制造商、品牌所有者、授权经销商和采购供应商分开；没有证据不建立制造关系。
7. **版本有效：** 记录创建/核验/生效日期、替代关系和适用范围；过期资料不得覆盖新版本。
8. **证据可定位：** 每个关键属性可追溯到来源文档、页码/章节、图号/表号或现场记录。
9. **安全与保密：** 不录入客户机密图纸、未授权供应商资料或含敏感资产信息的实物编号；受限文件只登记可合法保存的元数据。
10. **跨章无重复：** PART/MAT/PROCESS/BOM/PRODUCT/SUBSYS分别按主归属管理，其他章节通过ID引用。
