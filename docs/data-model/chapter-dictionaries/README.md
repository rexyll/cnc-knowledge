# 章节级数据字典

每个知识章节在需要管理结构化数据字段时，可在本目录创建独立字典文件，命名为CH01.csv至CH22.csv。字段定义以docs/templates/CHAPTER-DATA-DICTIONARY-TEMPLATE.csv为模板。

每个字段必须说明所属实体类型、字段名、中文标签、语义、数据类型、单位、必填级别、允许值、校验规则、适用机型/配置/版本、来源要求和必要备注。

本目录不预先填充未经研究的字段；章节尚未形成可靠数据需求时可以暂时没有对应CSV。字段定义应由章节任务驱动，避免为了填表制造无用或重复属性。


已建立首轮数据字典：CH01.csv（知识条目/术语字段）、CH02.csv（机床类型/型号字段）、CH03.csv（整机架构/机械接口字段）、CH04.csv（PART主数据字段）、CH08.csv（伺服轴控制环、辨识和多工况字段）、CH12.csv（扰动观测、补偿和模型验证字段）、CH19.csv（组织/品牌/产品字段）。字典用于后续结构化录入，示例值不是实际型号参数。
