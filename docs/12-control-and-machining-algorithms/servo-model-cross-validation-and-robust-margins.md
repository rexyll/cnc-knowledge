# 多工况对象模型、交叉验证与鲁棒稳定裕度评估

> 本专题从算法验证角度组织多工况辨识、模型复杂度、参数不确定性和闭环稳定裕度。所有合成结果与真实设备数据分开管理；模型拟合良好不等于闭环稳定或机床验收通过。

## 1. 统一试验数据模型

每组辨识数据应以一个试验身份标识，关联设备/轴/驱动/固件、参数版本、机械负载配置、夹紧和位置、方向/速度/加速度范围、温度测点、输入/输出通道与物理测点、校准证书、采样时钟、滤波/窗口、注入信号和数据文件哈希。

按目的拆分：
- **估计集：** 用于拟合候选模型参数。
- **留出验证集：** 用于评价候选模型在未参与拟合的数据上的预测/仿真误差。
- **重复性集：** 同工况重复记录，用于估计试验随机性、FRF离散程度与相干度。
- **工况外验证集：** 不同负载/方向/热状态的数据，用来检验一个模型是否能泛化，或证明需要模型族/参数调度。

训练/验证数据的频率内容、去趋势处理、窗函数和测量链应可比。若验证数据与估计数据在频带或预处理上不同，模型误差差异可能来自试验设计而非模型本身。官方系统辨识工作流同样强调独立验证和估计数据的可比性。[SRC-000334][SRC-000336]

## 2. H1频响、相干度和置信区间

对输入 \(u\) 与输出 \(y\) 的重复谱记录，H1估计器为：

\[
\hat G_{H1}(j\omega)=\frac{\hat S_{yu}(j\omega)}{\hat S_{uu}(j\omega)}
\]

幅值平方相干度为：

\[
\gamma^2_{yu}(\omega)=
\frac{|\hat S_{yu}(\omega)|^2}
{\hat S_{uu}(\omega)\hat S_{yy}(\omega)}
\]

相干度是输入与输出线性相关程度的诊断量，并非模型正确概率。低相干可能来自输出噪声、未测扰动、多输入耦合、非线性、时变或激励不足。应与重复试验离散度、频响置信区间、残差分析和输入/输出测量链一起解释。

估计频响的幅值/相位误差必须使用明确口径，例如复数FRF归一化RMSE、幅值dB误差、相位误差（注意相位展开和接近零幅值频点）、频率点coherence及置信区间、共振/反共振频率和跨工况漂移。

不要把单个频点、单一传感器或单次激励的相干度阈值直接推广为整机验收标准。

## 3. 候选模型阶次与选择原则

候选模型可从单惯量 \(1/(Js+B)\) 开始，再扩展到两惯量柔性对象或多惯量链模型。选择顺序：
1. 由结构、可用测点和实际观测到的模态数提出候选；
2. 检查参数可辨识性、模型极点/零点、物理参数范围和残差；
3. 使用AICc/BIC/FPE等指标考虑参数数量；
4. 使用独立频响或时域记录评价留出误差；
5. 在不同负载、方向和热状态上检查模型有效性；
6. 只有新增模态在测量中可重复且提升留出表现时，才保留更高阶模型。

信息准则并非跨数据长度、噪声估计方式和残差缩放的绝对排名。比较前应统一残差定义、样本数和通道权重。若高阶模型训练误差继续下降、但留出误差不再改善甚至恶化，应检查过拟合和参数不确定性。[SRC-000335][SRC-000336]

## 4. 多工况模型集合和不确定性包络

对于每个工况 \(c\)，记录对应对象 \(P_c(s)\)。选取参考工况作为名义模型 \(P_n(s)\)，可定义乘性差异：

\[
\Delta_{m,c}(s)=\frac{P_c(s)-P_n(s)}{P_n(s)}
\]

该表达式在名义模型接近零点、传递路径零值或传感器/执行器通道不一致处可能数值病态；这些频段应使用加性差异或其他经推导的因子化方式，不能盲目除以接近零的 \(P_n\)。

模型集合可表达负载/热状态/方向下的变化，但必须说明：
- 模型是否采用同一输入/输出坐标和相同物理测点；
- 参数差异是辨识置信区间、工况变化范围还是模型结构不确定性；
- 频率范围内测得的数据是否足够覆盖控制目标带宽；
- 未测频段如何处理，是未知、外推还是采用有证据的物理约束；
- 观测到的离散来自试验重复性、测量误差还是工况本身变化。

不能把少量合成样本或单一热态测试直接当作真实设备不确定性上界。

## 5. 闭环稳定裕度的正确计算边界

稳定裕度评估必须以实际闭环为对象，不是给对象模型贴稳定标签。记录至少包含：
- 开环环路断点、正/负反馈符号、测量点和注入点；
- 控制器结构/参数版本、电流/速度/位置环状态与多环拓扑；
- 采样周期、计算/总线/滤波延迟；
- 执行器动态、限幅/饱和及工作点；
- 对应负载/温度/方向下的对象模型或模型族。

对SISO单环，经典增益裕度和相位裕度需记录全部相关交越频率，尤其存在多个0 dB或-180°交越时。对MIMO/多环系统，逐环margin可能遗漏环间交互；disk margin以同时增益/相位变化和多环相互作用为分析对象，但结果依赖准确闭环互连和环路断点。[SRC-000337]

推荐将裕度分析分为：每个工况的名义闭环极点/稳定性检查；经典增益/相位裕度和全部交越点；多环disk margin或适用鲁棒稳定分析；模型集合/不确定性下的最坏情况裕度；执行器饱和、摩擦、死区、采样抖动等非线性/时变边界仿真；经批准的SIL/HIL/台架和实机验证。

本轮仿真只做对象辨识和模型阶次选择，未设计控制器，也没有可用于计算裕度的闭环互连，因此不输出数值GM/PM/disk margin。不得从对象FRF、AICc或相干度推导闭环稳定结论。

## 6. 合成验证结果摘要

脚本在名义冷态、较重负载冷态、较重负载热态三种两惯量对象上，以及一个三惯量参考对象上，分别估计H1频响，再拟合1/2/3惯量候选模型。四个场景的AICc选择阶次依次为2、2、2、3。验证NRMSE结果见CH08配套专题和CSV。

在两惯量工况下，1惯量验证误差约0.22～0.32，二/三惯量模型约0.003；AICc选择参数更少的两惯量模型。在三惯量参考对象中，三惯量留出误差约0.003，而两惯量模型约0.071，支持选择额外自由度。上述是已知真值合成模型的自检，不是实际设备辨识准确率或机床性能。
