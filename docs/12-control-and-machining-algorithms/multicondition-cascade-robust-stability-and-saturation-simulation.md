# 多工况伺服级联控制的稳定裕度与限幅仿真

> 本文将多工况伺服对象模型接入单轴SISO级联控制示例，联合研究负载变化、参数变体、采样延迟、柔性模态、转矩饱和和抗积分饱和。全部数值为合成结果，不是实机测量、验收阈值或生产调参推荐。

**更正说明（2026-11-22）：** 旧版曾将两惯量相对扭转约化惯量误用为刚体总惯量，且阶跃反馈缓存多初始化了一个采样。现已修正控制器增益、延迟样本数、频域/时域结果；旧版数字均由本版及同目录CSV替代。正确刚体惯量为两侧折算到同一轴侧后之和，约化惯量只用于相对扭转模态。

## 1. 环路断点与信号路径

采用电机侧速度反馈、负载侧位置反馈。速度PI输出转矩命令，经过一阶电流/转矩执行器近似后作用到机械对象；位置P控制器把负载位置误差转换为速度参考。频域分别定义：

- 速度环开环 \(L_\omega(s)=C_\omega(s)A_i(s)G_{\omega_mT}(s)\)，反馈量为电机侧速度；
- 位置外环开环 \(L_\theta(s)=K_{p\theta}C_\omega(s)A_i(s)G_{\theta_lT}(s)/(1+L_\omega(s))\)，是在速度闭环成立时的负载侧位置环等效开环。

其中 \(A_i(s)=1/(\tau_i s+1)\)，\(C_\omega(s)=K_{p\omega}+K_{i\omega}/s\)，两个对象传递函数分别表示电机转矩到电机速度、以及电机转矩到负载位置的响应。该定义只适用于本轮固定SISO结构，不可不加说明搬到环路部署位置、反馈点或双反馈结构不同的设备。

## 2. 合成对象与延迟

| 对象 | 惯量/模态 | 轴系刚度 \(K_s\) | 说明 |
|---|---|---:|---|
| nominal_cold | 两惯量，\(J_m=0.010,\ J_l=0.020\) kg·m² | 1400 N·m/rad | 名义冷态 |
| heavy_load_cold | 两惯量，\(J_m=0.010,\ J_l=0.032\) kg·m² | 1400 N·m/rad | 增加负载惯量 |
| heavy_load_hot | 两惯量，\(J_m=0.010,\ J_l=0.032\) kg·m² | 1260 N·m/rad | 手动设置的热态刚度/阻尼变体 |
| three_mode_reference | 三惯量，两个柔性耦合 | 1200 / 850 N·m/rad | 额外模态参考对象 |

阻尼、库仑摩擦、执行器时间常数、转矩上限、速度参考上限和扰动幅值也都是模型假设。heavy_load_hot只是手动参数变体，不拟合温度—材料—刚度的真实物理关系。

控制采样周期0.5 ms，反馈延迟扫描0、0.5、1.0 ms；非线性时域仿真通过整数采样缓存实现。内层转矩执行器简化为时间常数1 ms的一阶环节，机械对象在每个采样区间内用4步RK4推进。频域相位采用 \((d+0.5)T_s\) 的等效延迟，其中 \(d\) 是反馈延迟样本数，额外半采样是ZOH相位粗略近似，不是精确数字闭环。延迟会产生附加相位变化并影响稳定性，真实设计应以准确内部延迟或离散模型复核。[SRC-000339]

本轮线性模型不包括转矩饱和、库仑摩擦和速度参考限幅。非线性时域仿真则加入±1 N·m转矩限幅、±1.5 rad/s速度参考限幅、反算型抗积分饱和（tracking time constant 30 ms），以及0.25 N·m、持续0.40～0.70 s的负载扰动。PID实现可使用back-calculation/clamping等抗积分饱和机制，但实际实现取决于控制器结构和离散化方式。[SRC-000338]

## 5. 工程闭环建议

1. 锁定驱动器/电机/反馈/机械轴系身份、参数与固件版本，保留参数备份；
2. 在不同负载、方向、轴位置和热状态下辨识对象，保留有效频带和重复性；
3. 明确各环部署位置、反馈点、注入点、环路断点、符号与单位；
4. 先设计/验证内环，再闭合速度环、位置环；每次变更保留版本；
5. 在每个工况计算全部交越点及GM/PM，再按准确多环闭环互连计算disk margin或适用鲁棒指标；
6. 将采样/总线/计算延迟、滤波、限幅、摩擦、死区、柔性模态和扰动加入离散/非线性模型回归；
7. 经批准后进行SIL、HIL、台架和实机逐级验证，记录异常与恢复证据。

存在环间耦合的MIMO系统，逐个SISO环路裕度不能完整描述所有交互；disk margin需准确闭环互连、环路断点和通道定义。[SRC-000337] 本轮仅做SISO示例，不输出disk margin。

## 6. 资源和禁止外推项

- Python 3.10+、NumPy即可运行；脚本生成24条频域扫描、24条时域记录和配置JSON。
- 对象参数、温态变体、执行器时间常数、延迟、转矩/速度上限、摩擦和扰动均为人为设定，不是厂商参数或真实机床测量。
- 未仿真PMSM电气动态、逆变器开关、电流采样偏置、编码器量化、总线抖动、热传导/热弹性、MIMO多轴耦合及真实驱动器实现。
- 频域等效延迟和零速连续极点检查有近似边界；签核设计必须以实际离散实现和完整互连复核。
- CI只检查仓库结构、Schema、来源引用和链接，不验证仿真在真实机床上的准确性、稳定性、机械兼容或安全。

本文不提供生产级参数、设备验收门槛、实际热态模型、真实GM/PM/disk margin或机床性能承诺。
