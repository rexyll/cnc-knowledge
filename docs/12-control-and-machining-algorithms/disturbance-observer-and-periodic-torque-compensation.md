# 扰动观测器与直驱回转轴周期转矩补偿

**章节：** CH12 — 控制与加工算法  
**主题边界：** 本文从算法层讨论扰动观测、周期扰动映射、摩擦补偿和回归验证。电流环/速度环/位置环结构见[CH08伺服级联控制](../08-servo-spindle-and-motion-control/servo-cascade-control.md)；电机/编码器物理误差来源见[CH04直接驱动诊断专题](../04-components-materials-and-manufacturing/manufacturing-processes.md)。

## 1. 补偿之前先定义扰动对象

直驱回转轴的低速顿挫、速度纹波或角度误差可能来自不同层级。补偿对象不清晰时，容易把错误模型写进补偿表，或使用控制器功能掩盖机械缺陷。

| 扰动类别 | 典型来源 | 更适合观察的信号/坐标 |
|---|---|---|
| 电磁周期扰动 | 齿槽转矩、磁链/反电势谐波、磁阻转矩 | 转子机械角、电角度、相电流/转矩电流 |
| 电流控制误差 | 电流传感器偏置/增益、采样时序、逆变器死区/电压非线性 | 三相电流、d/q电流、PWM/采样触发 |
| 机械摩擦扰动 | 粘滑、轴承/密封/线缆/软管拖曳、夹紧残余拖曳 | 速度方向、起动/换向阈值、外部转矩 |
| 负载扰动 | 工件/夹具惯量变化、切削负载、重力或外部扰动 | 输出端角度/速度、负载估计/转矩传感器 |
| 反馈扰动 | 编码器偏心、正余弦幅值/相位误差、插值和采样延迟 | 原始反馈信号、电机端/输出端交叉测量 |
| 结构/控制动态 | 支承柔度、轴系共振、控制环带宽或滤波交互 | 时间频率、机械阶次、驱动电流和振动 |

Siemens的1FW3完整式力矩电机配置手册在其规定的电机型号和驱动条件下给出slot ripple和torque accuracy数据，并说明转矩纹波还可能与编码器分辨率及逆变器电压设定分辨率有关；这些参数仅适用于手册明确列出的电机/驱动配置，不可外推为其他力矩电机或整机轴的验收限值。[SRC-000322]

## 2. 常用补偿方法及其适用对象

| 方法 | 主要目标 | 优势 | 风险/限制 |
|---|---|---|---|
| 轨迹前馈 | 惯量/阻尼等可预测轨迹需求 | 减轻反馈环路负担 | 模型/负载错误会导致过补偿 |
| 摩擦补偿 | 库仑摩擦、粘滑或方向相关阻力 | 可改善低速起动/换向误差 | 死区、不连续切换可能引入抖振或极限环 |
| 位置相关扰动表 | 重复的机械角/电角度周期扰动 | 对相位稳定、可重复的周期扰动有效 | 零位漂移、负载/温度变化和反馈误差会破坏表格有效性 |
| 电流/电压谐波补偿 | 电磁谐波和逆变器相关周期项 | 能在更靠近电流/转矩生成端的位置抑制特定分量 | 需要准确的电气角、采样时序和电流带宽 |
| 扰动观测器（DOB） | 低/中频未建模负载和模型扰动 | 可估计并抵消一类等效扰动 | 依赖名义模型、Q滤波和鲁棒稳定性，不会自动识别具体物理故障 |
| 重复控制/迭代学习 | 周期轨迹或重复工况中的可重复误差 | 可利用上一周期误差改善下一周期表现 | 非重复工况、周期时间变化或噪声会降低学习效果 |
| 陷波/低通滤波 | 特定共振/噪声频段 | 可降低闭环对目标频段的响应 | 不是转矩源头补偿；会改变相位/延迟并可能影响稳定性 |

## 3. 扰动观测器（DOB）的基本模型

### 3.1 名义对象和输入扰动定义

考虑扰动 (d) 与控制输入 (u) 以相同输入通道进入对象的简化模型：

[
y(s)=P(s)[u(s)+d(s)]
]

(P(s)) 为真实对象，(P_n(s)) 为用于观测器的名义对象。若 (P=P_n)，则理想地有：

[
P_n^{-1}(s)y(s)-u(s)=d(s)
]

实际实现加入稳定低通Q滤波器：

[
\hat d(s)=Q(s)\left[P_n^{-1}(s)y(s)-u(s)\right]
]

再以相反符号把估计扰动叠加到控制输入：

[
u_c(s)=u_{fb}(s)-\hat d(s)
]

以上采用“扰动与控制输入同号相加”的定义。如果实际系统把扰动定义为负载转矩、且机械方程写成 (J\dot\omega=T_m-T_L)，观测器符号需按具体框图重新定义，不能直接套公式的正负号。

### 3.2 回转轴的速度对象示例

对简化机械轴，控制输入为电机转矩、输出为角速度时：

[
P_n(s)=\frac{\omega(s)}{T_m(s)}
=\frac{1}{J_n s+B_n}
]

(J_n) 是名义等效惯量，(B_n) 是名义粘性阻尼。实际轴还包含摩擦、柔性模态、采样延迟、速度滤波、负载/夹具变化和电流环动态，不能仅用 (1/(J_ns+B_n)) 代表整个数控轴。

DOB对这些未建模项往往只估计为“等效扰动”。它能帮助判断控制器需要抵消多少扰动，但不能仅凭 (hat d) 的数值区分齿槽转矩、摩擦、切削负载或编码器误差。

## 4. Q滤波器：带宽、噪声和模型鲁棒性的折衷

Q滤波器通常设计为低通，以使扰动估计可实现并抑制高频测量噪声。其相对阶次、稳定性和名义对象逆模型必须一并检查；最小相位假设和非最小相位对象的实现方式也需审查。[SRC-000324]

一个常见的二阶低通示例为：

[
Q(s)=\frac{\omega_c^2}{s^2+2\zeta\omega_c s+\omega_c^2}
]

该式只是结构例子，不是推荐的通用Q滤波器。截止频率提高，可能增强某些频段的扰动估计，却同时提高对传感器噪声、采样延迟和名义模型不准确的敏感度；实际带宽必须受未建模共振、采样率、驱动电流环带宽和执行器能力约束。[SRC-000324][SRC-000325]

设计/验证至少应回答：
- (P_n(s)) 的输入/输出量、单位和符号是否与扰动定义一致？
- 名义惯量/阻尼来自哪次辨识？负载变化时如何更新？
- (Q(s)) 是否稳定、可实现、无不适当的高频增益？
- 观测器在目标频段是否降低扰动，同时不放大噪声和未建模共振？
- 电流/电压限幅时估计量是否仍可信？抗饱和和补偿限幅如何处理？
- 加载/卸载、正反向和温度变化是否会导致估计偏差？

## 5. 位置相关的齿槽/周期扰动映射

### 5.1 机械角、电角度和表格索引

若扰动与转子角度稳定相关，可定义机械角 (	heta_m) 或电角度 (	heta_e=p\theta_m+	heta_0) 的周期函数：

[
T_d(\theta)=a_0+\sum_{k=1}^{N}
\left[a_k\cos(k\theta)+b_k\sin(k\theta)\right]
]

也可以使用离散角度表 (hat T_d[i])。若补偿通过q轴电流命令实现，在简单PMSM转矩常数近似成立时：

[
i_{q,comp}(\theta)=-\frac{\hat T_d(\theta)}{K_t}
]

(K_t) 必须是对应电机/工作点/控制策略下适用的转矩—电流关系。IPMSM、弱磁、饱和和高动态工况不能默认使用固定常数转换。

关键治理字段：
- 表格索引使用机械角还是电角度，零位/方向/极对数如何定义；
- 反馈使用电机端还是输出端编码器，是否存在两个测量点之间的柔性/偏差；
- 表格分辨率、插值方式、周期边界连续性和角度同步时间戳；
- 是否分CW/CCW表，换向/零速附近如何切换；
- 学习时的速度、负载、温度、夹紧释放和冷却条件；
- 补偿输出限幅、电流/电压饱和和安全互锁。

Siemens SINAMICS S120资料展示了基于电机测量系统位置查表的齿槽转矩补偿，并可使用方向专属表；其功能对编码器身份、驱动固件和电流/电压工作区间有明确限制。[SRC-000313] 这些限制仅支持相应S120功能说明，不能据此假设其他驱动器具备同样功能。

### 5.2 学习/标定前提

在建立位置相关补偿表之前，应尽可能确认：
1. 定子/转子气隙、偏心、轴承和输出支承已通过机械检查；
2. 夹紧机构确实释放，没有线缆/软管/密封异常拖曳；
3. 编码器原始信号、零位、方向和反馈同步已确认；
4. 电机相序、换相角、电流采样和转矩电流映射可追溯；
5. 测试负载、惯量、温度、速度和方向可重复；
6. 采集系统的转矩/位置测量带宽和校准适合目标周期成分。

如果补偿表把偏心、编码器环误差、摩擦或机械擦碰“学进去”，其结果可能只在学习时的工况有效，并会在不同方向、温度或负载下产生反向/过量补偿。

## 6. 摩擦补偿与低速粘滑

一种简化摩擦模型为：

[
T_f(\omega)=T_c\operatorname{sgn}(\omega)+B\omega
]

其中 (T_c) 是库仑摩擦项，(B\omega) 是粘性摩擦项。实际低速区还可能有静摩擦峰值、Stribeck效应、方向迟滞和密封/线缆拖曳。符号函数在零速处不连续，直接叠加容易引起指令跳变或极限环；平滑近似/死区策略虽可减轻不连续，也会改变补偿精度和起动行为。

摩擦补偿只适用于被辨识到的可重复摩擦模型，且需验证正反向起动阈值、低速恒速电流、零速附近抖动、多速度/负载和热态参数漂移，以及夹紧/密封/轴承/线缆机械问题是否排除。

不要把静态保持、夹紧力矩或蜗杆自锁能力作为摩擦补偿模型的一部分混合使用。

## 7. 周期谐波补偿、重复控制和迭代学习

### 7.1 电流/电压谐波前馈

若确认扰动按电角度周期重复，可以在相应控制层叠加谐波项，例如：

[
u_h(\theta_e)=\sum_{k=1}^{N}
\left[c_k\sin(k\theta_e)+d_k\cos(k\theta_e)\right]
]

补偿项可能作用于电流参考、d/q电压或其他驱动内部变量，必须与所用控制器架构一致。不同电机拓扑的主导谐波与相位不一样；电角度零偏、极对数和电流采样误差都会影响效果。

研究论文展示了DOB电流控制抑制与转子位置同步的PMSM电流纹波，也有研究用鲁棒两自由度控制、扩展滑模参数观测器和迭代学习联合抑制周期扰动。[SRC-000323][SRC-000325] 这些结果只能说明可研究的算法路径，论文实验电机和平台的结果不能直接预测数控转台性能。

2026年一项低速PMSM研究提出电流平均和谐波电压注入方法；其应用假设和验证平台不是数控机床直驱回转轴，故只作为算法文献线索，不能视为CNC轴的已验证解决方案。[SRC-000326]

### 7.2 重复控制/迭代学习

重复控制适合周期参考/周期扰动下的稳态误差抑制；迭代学习控制适合重复执行、周期长度和初始条件足够一致的轨迹任务。两者都要考虑学习增益、相位补偿、滤波、周期同步和收敛条件。工件负载、加工过程、温度或轨迹周期变化很大时，历史周期误差未必能代表当前扰动。

## 8. 补偿试验和回归验证

| 阶段 | 试验内容 | 必须冻结/记录 |
|---|---|---|
| A. 原始基线 | 补偿关闭，做静态/准静态角度—转矩、低速CW/CCW和多速度扫描 | 电机/驱动/编码器身份、参数版本、负载、温度、测量链 |
| B. 模型辨识 | 估计 (J,B,T_f)，记录扰动角度映射或频率成分 | 识别方法、激励/采样、模型残差、负载和校准状态 |
| C. 仿真/离线回放 | 用同一组原始数据对比无补偿/候选补偿 | 算法版本、量化/延迟、限幅、噪声和数据划分 |
| D. 受控启用 | 由设备负责人批准后逐项启用一种补偿功能 | 参数增量、使能状态、限幅/保护和停机条件 |
| E. 回归 | 重复CW/CCW、低速/多速度、多负载和冷/热态试验 | 与基线相同的测量点、带宽、窗口和工况 |
| F. 整机评价 | 单轴定位、回转轴线运动、协调轨迹和加工质量试验 | 目标机床标准/合同、工件/夹具、补偿开关和最终参数备份 |

至少比较平均误差、峰峰值/RMS扰动、指定机械角/电角度阶次、速度纹波、位置跟随误差、输出端独立角度误差、电流噪声、振动和温升。任何百分比指标都要定义分母；平均转矩接近零时不以波动百分比代替绝对物理量。

## 9. 验证层级与安全边界

- **数学/单元测试：** 检查模型符号、单位、极限条件、表格周期连续性、插值、限幅、饱和和数值溢出。
- **离线数据回放：** 以真实或明确标记的仿真数据验证算法，不将模拟结果标记为实机测试。
- **SIL/HIL/台架：** 需匹配驱动采样周期、反馈延迟、PWM/电流限制和机械负载模型。
- **实机验证：** 由有资质人员依目标机床/驱动手册和风险评估批准；检查急停、限位、夹紧/松夹、负载支撑、运动范围和保护状态。

不得通过禁用反馈/保护、绕过联锁或在未知机械状态下强制运行来“验证”补偿算法。若存在转子擦碰、轴承异常、编码器故障、过温或非预期转动，应先按设备安全程序停止并排除机械/电气故障。
