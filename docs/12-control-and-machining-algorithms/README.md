# 12. 控制与加工算法

**English:** Control and Machining Algorithms  
**范围：** 插补、轨迹规划、加减速、前瞻、坐标变换、误差补偿、主轴/进给控制、加工优化和算法验证。

## 本章覆盖内容

- 直线/圆弧/样条插补、多轴插补和高阶曲线
- 速度规划、加速度/跃度约束、前瞻和拐角平滑
- 坐标变换、刀具半径/长度补偿、RTCP和运动学变换
- 螺距/反向间隙/直线度/垂直度/热误差补偿
- 振动抑制、切削参数优化、负载监测和加工误差分析
