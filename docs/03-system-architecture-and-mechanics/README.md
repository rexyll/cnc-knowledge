# 03. 整机架构与机械结构

**English:** System Architecture and Mechanical Systems  
**范围：** 整机功能架构、床身与基础件、运动部件、导轨丝杠、主轴、传动、润滑、冷却、防护和排屑等机械系统。

## 本章覆盖内容

- 整机分层架构、功能子系统、运动链和能量/信息流
- 床身、底座、立柱、横梁、滑鞍、工作台、转台和结构布局
- 滚动/滑动导轨、滚珠丝杠、齿轮齿条、联轴器和轴承
- 主轴单元、刀库换刀机构、润滑、液压、气动、冷却、排屑和防护
