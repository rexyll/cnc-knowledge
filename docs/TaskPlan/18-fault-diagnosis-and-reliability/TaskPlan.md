# 18. 故障诊断与可靠性 — 章节任务计划

**章节编号：** CH18  
**英文名称：** Fault Diagnosis and Reliability  
**对应正文：** `docs/18-fault-diagnosis-and-reliability/`  
**资源归档：** `resouces/18-fault-diagnosis-and-reliability/`  
**章节范围：** 机械、电气、数控、伺服、通信、软件和加工质量故障，以及根因分析、可靠性、可维护性和故障统计。

> 本文件只拆解本章知识建设任务，统一继承根目录 `TaskPlan.md` 的全部 Guide、Limit、质量标准、资源规则、版权要求和安全要求。

## 1. 章节目标

建立本章节系统化、可验证、可检索且能够与其他知识板块关联的技术资料。按“概念分类—原理结构—参数与型号—工程应用—测试/维护—案例”逐步完善，避免只堆积无上下文的链接或参数表。

## 2. 覆盖范围

- 机械振动、异响、精度漂移、温升、润滑和传动故障
- 电源、传感器、I/O、接线、驱动器和保护报警
- CNC/PLC报警、伺服报警、通信中断、同步异常和软件异常
- 故障树、FMEA、5Why、MTBF/MTTR、备件和预防维护

## 3. 任务节点

- **目标：** 定义故障编码、系统归属、严重度、现象、状态和影响范围。
- **工作范围：** 机械振动、异响、精度漂移、温升、润滑和传动故障；电源、传感器、I/O、接线、驱动器和保护报警；CNC/PLC报警、伺服报警、通信中断、同步异常和软件异常；故障树、FMEA、5Why、MTBF/MTTR、备件和预防维护。
- **交付物：** 故障分类树、故障记录模板、术语表。
- **验收标准：** 故障可链接至机型、系统、部件、报警、维修措施和证据。
- **依赖：** CH03-CH13
