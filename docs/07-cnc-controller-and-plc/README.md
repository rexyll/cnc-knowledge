# 07. 数控系统、控制器与 PLC

**English:** CNC Controller and PLC  
**范围：** CNC数控装置、插补控制、PLC逻辑、HMI控制接口、I/O、机床参数、宏程序、通道和数控系统配置。

## 本章覆盖内容

- CNC控制器硬件、软件模块、通道和轴配置
- 机床PLC、梯形图/功能块、顺序控制、M代码及辅助功能
- 机床参数、伺服参数、补偿表、宏变量和数据备份
- 数控系统品牌、系列、选件、接口与配置差异
