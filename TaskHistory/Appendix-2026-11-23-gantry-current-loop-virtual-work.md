# 进给轴电流受控驱动状态与执行器虚功接口解析扩展（2026-11-23）

## 工作范围
补充自由路径坐标联合模型中的电流受控执行器最低阶状态接口、PI环与限幅边界，以及执行器两作用端相对位移雅可比的广义力投影。

## 新增内容
- 线性驱动最低阶等效电气模型：\(L_e\dot i_q=u_q-R_ei_q-K_e\dot\ell_a\)，\(F_a=K_fi_q\)；明确它不是通用PMSM完整dq模型。
- 电流PI、逆变器电压限幅和anti-windup模型边界；不假设具体驱动器固件。
- 执行器相对位移 \(\ell_a(z)\) 的雅可比 \(J_a=\partial\ell_a/\partial z\) 与广义力 \(Q_a=J_a^TF_a\)，避免漏计或重复计驱动反力。
- 联合状态组织、采样/连续更新次序和测试边界：功率符号、反电势、零速、正反向、电压/电流限幅、PI积分/复位、虚功投影和能量耗散。
