# 每日任务历史

本目录按日期记录知识库任务的实际完成情况。文件命名格式为 `TaskHistory-YYYY-MM-DD.md`，统一采用 `Asia/Shanghai`（UTC+08:00）时间。

## 记录要求

每项记录至少包括任务ID、任务名称、实际完成时间（ISO 8601）、分支、提交SHA、交付文件/资源、来源或验收证据、完成结论和遗留事项。

只记录实际完成且通过适用验收的任务。未完成内容放入“进行中/阻塞/下一步”，不得提前标记DONE。更正历史时保留更正说明，不静默覆盖原记录。

根目录 `TaskPlan.md` 保存全局规则和里程碑状态；每日详细执行过程统一放在此目录。
