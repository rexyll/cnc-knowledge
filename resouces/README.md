## 归档要求

- 图片、动图和完整文档统一存放到对应章节目录；保留用户指定的目录拼写resouces。
- 文件必须登记来源、取得/生成日期、版本、许可或授权状态、关联知识条目；适用时记录SHA-256。
- 对无权保存或权利状态不明的外部资料，仅记录可合法保存的元数据、摘要和官方链接，不复制完整文件。
- 跨章节使用同一资料时，只在主归属章节保存一份，其他章节通过相对路径引用。
- 更详细规则见根目录TaskPlan.md及每个章节的ASSET-INDEX.md。
